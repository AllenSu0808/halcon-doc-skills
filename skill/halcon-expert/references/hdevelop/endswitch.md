# endswitch (Operator)

## Name

`endswitch` — Ends a multiway branch block.

## Signature

`endswitch( : : : )`

## Description

`endswitch` ends a multiway branch block that has been opened by
[`switch`](switch.md).

## Result

`endswitch` always returns 2 (
H_MSG_TRUE)
.
