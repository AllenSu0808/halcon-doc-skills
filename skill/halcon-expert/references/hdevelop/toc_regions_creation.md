## Creation

#### List of Operators

- [`gen_checker_region`](gen_checker_region.md) — Create a checkered region.

- [`gen_circle`](gen_circle.md) — Create a circle.

- [`gen_circle_sector`](gen_circle_sector.md) — Create a circle sector.

- [`gen_ellipse`](gen_ellipse.md) — Create an ellipse.

- [`gen_ellipse_sector`](gen_ellipse_sector.md) — Create an ellipse sector.

- [`gen_empty_region`](gen_empty_region.md) — Create an empty region.

- [`gen_grid_region`](gen_grid_region.md) — Create a region from lines or pixels.

- [`gen_random_region`](gen_random_region.md) — Create a random region.

- [`gen_random_regions`](gen_random_regions.md) — Create random regions like circles, rectangles and ellipses.

- [`gen_rectangle1`](gen_rectangle1.md) — Create a rectangle parallel to the coordinate axes.

- [`gen_rectangle2`](gen_rectangle2.md) — Create a rectangle of any orientation.

- [`gen_region_contour_xld`](gen_region_contour_xld.md) — Create a region from an XLD contour.

- [`gen_region_histo`](gen_region_histo.md) — Convert a histogram into a region.

- [`gen_region_hline`](gen_region_hline.md) — Store input lines described in Hesse normal form as regions.

- [`gen_region_line`](gen_region_line.md) — Store input lines as regions.

- [`gen_region_points`](gen_region_points.md) — Store individual pixels as image region.

- [`gen_region_polygon`](gen_region_polygon.md) — Store a polygon as a region.

- [`gen_region_polygon_filled`](gen_region_polygon_filled.md) — Store a polygon as a “filled” region.

- [`gen_region_polygon_xld`](gen_region_polygon_xld.md) — Create a region from an XLD polygon.

- [`gen_region_runs`](gen_region_runs.md) — Create a region from a runlength coding.

- [`label_to_region`](label_to_region.md) — Extract regions with equal gray values from an image.
