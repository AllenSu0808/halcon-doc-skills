## Type

#### List of Operators

- [`tuple_is_handle`](tuple_is_handle.md) — Test if the internal representation of a tuple is of type `handle`.

- [`tuple_is_handle_elem`](tuple_is_handle_elem.md) — Test whether the elements of a tuple are of type `handle`.

- [`tuple_is_int`](tuple_is_int.md) — Test if the internal representation of a tuple is of type `integer`.

- [`tuple_is_int_elem`](tuple_is_int_elem.md) — Test whether the types of the elements of a tuple are of type
  `integer`.

- [`tuple_is_mixed`](tuple_is_mixed.md) — Test whether a tuple is of type `mixed`.

- [`tuple_is_nan_elem`](tuple_is_nan_elem.md) — Check a tuple whether it represents NaNs (Not-a-number).

- [`tuple_is_number`](tuple_is_number.md) — Check a tuple (of strings) whether it represents numbers.

- [`tuple_is_real`](tuple_is_real.md) — Test if the internal representation of a tuple is of type `real`.

- [`tuple_is_real_elem`](tuple_is_real_elem.md) — Test whether the types of the elements of a tuple are of type `real`.

- [`tuple_is_string`](tuple_is_string.md) — Test if the internal representation of a tuple is of type `string`.

- [`tuple_is_string_elem`](tuple_is_string_elem.md) — Test whether the types of the elements of a tuple are of type
  `string`.

- [`tuple_is_valid_handle`](tuple_is_valid_handle.md) — Check if a handle is valid.

- [`tuple_sem_type`](tuple_sem_type.md) — Return the semantic type of a tuple.

- [`tuple_sem_type_elem`](tuple_sem_type_elem.md) — Return the semantic type of the elements of a tuple.

- [`tuple_type`](tuple_type.md) — Return the type of a tuple.

- [`tuple_type_elem`](tuple_type_elem.md) — Return the types of the elements of a tuple.
