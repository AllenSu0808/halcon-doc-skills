## Serialized Item

#### List of Operators

- [`clear_serialized_item`](clear_serialized_item.md) — Delete a serialized item.

- [`create_serialized_item_ptr`](create_serialized_item_ptr.md) — Create a serialized item.

- [`decrypt_serialized_item`](decrypt_serialized_item.md) — Decrypt an encrypted item.

- [`encrypt_serialized_item`](encrypt_serialized_item.md) — Encrypt a serialized item.

- [`fread_serialized_item`](fread_serialized_item.md) — Read a serialized item from a file.

- [`fwrite_serialized_item`](fwrite_serialized_item.md) — Write a serialized item to a file.

- [`get_serialized_item_ptr`](get_serialized_item_ptr.md) — Access the data pointer of a serialized item.
