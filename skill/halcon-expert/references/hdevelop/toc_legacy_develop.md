## Develop

#### List of Operators

- [`dev_map_par`](dev_map_par.md) — Open the dialog to specify the visualization parameters.

- [`dev_map_prog`](dev_map_prog.md) — Make the main window of HDevelop visible.

- [`dev_map_var`](dev_map_var.md) — Open the variable window of HDevelop.

- [`dev_unmap_par`](dev_unmap_par.md) — Closes the dialog to specify the visualization parameters.

- [`dev_unmap_prog`](dev_unmap_prog.md) — Hide the main window.

- [`dev_unmap_var`](dev_unmap_var.md) — Hides the variable window.
