## Support Vector Machines

#### List of Operators

- [`add_class_train_data_svm`](add_class_train_data_svm.md) — Add training data to a support vector machine (SVM).

- [`add_sample_class_svm`](add_sample_class_svm.md) — Add a training sample to the training data of a support vector
  machine.

- [`classify_class_svm`](classify_class_svm.md) — Classify a feature vector by a support vector machine.

- [`clear_class_svm`](clear_class_svm.md) — Clear a support vector machine.

- [`clear_samples_class_svm`](clear_samples_class_svm.md) — Clear the training data of a support vector machine.

- [`create_class_svm`](create_class_svm.md) — Create a support vector machine for pattern classification.

- [`deserialize_class_svm`](deserialize_class_svm.md) — Deserialize a serialized support vector machine (SVM).

- [`evaluate_class_svm`](evaluate_class_svm.md) — Evaluate a feature vector by a support vector machine.

- [`get_class_train_data_svm`](get_class_train_data_svm.md) — Get the training data of a support vector machine (SVM).

- [`get_params_class_svm`](get_params_class_svm.md) — Return the parameters of a support vector machine.

- [`get_prep_info_class_svm`](get_prep_info_class_svm.md) — Compute the information content of the preprocessed feature vectors
  of a support vector machine

- [`get_sample_class_svm`](get_sample_class_svm.md) — Return a training sample from the training data of a support vector
  machine.

- [`get_sample_num_class_svm`](get_sample_num_class_svm.md) — Return the number of training samples stored in the training data of
  a support vector machine.

- [`get_support_vector_class_svm`](get_support_vector_class_svm.md) — Return the index of a support vector from a trained support vector
  machine.

- [`get_support_vector_num_class_svm`](get_support_vector_num_class_svm.md) — Return the number of support vectors of a support vector machine.

- [`read_class_svm`](read_class_svm.md) — Read a support vector machine from a file.

- [`read_samples_class_svm`](read_samples_class_svm.md) — Read the training data of a support vector machine from a file.

- [`reduce_class_svm`](reduce_class_svm.md) — Approximate a trained support vector machine by a reduced support
  vector machine for faster classification.

- [`select_feature_set_svm`](select_feature_set_svm.md) — Selects an optimal combination of features to classify the provided data.

- [`serialize_class_svm`](serialize_class_svm.md) — Serialize a support vector machine (SVM).

- [`train_class_svm`](train_class_svm.md) — Train a support vector machine.

- [`write_class_svm`](write_class_svm.md) — Write a support vector machine to a file.

- [`write_samples_class_svm`](write_samples_class_svm.md) — Write the training data of a support vector machine to a file.
