## Output

#### List of Operators

- [`disp_arc`](disp_arc.md) — Displays circular arcs in a window.

- [`disp_arrow`](disp_arrow.md) — Displays arrows in a window.

- [`disp_channel`](disp_channel.md) — Displays images with several channels.

- [`disp_circle`](disp_circle.md) — Displays circles in a window.

- [`disp_color`](disp_color.md) — Displays a color (RGB) image

- [`disp_cross`](disp_cross.md) — Displays crosses in a window.

- [`disp_ellipse`](disp_ellipse.md) — Displays ellipses.

- [`disp_image`](disp_image.md) — Displays gray value images.

- [`disp_line`](disp_line.md) — Draws lines in a window.

- [`disp_obj`](disp_obj.md) — Displays image objects (image, region, XLD).

- [`disp_object_model_3d`](disp_object_model_3d.md) — Display 3D object models.

- [`disp_polygon`](disp_polygon.md) — Displays a polyline.

- [`disp_rectangle1`](disp_rectangle1.md) — Display of rectangles aligned to the coordinate axes.

- [`disp_rectangle2`](disp_rectangle2.md) — Displays arbitrarily oriented rectangles.

- [`disp_region`](disp_region.md) — Displays regions in a window.

- [`disp_xld`](disp_xld.md) — Display an XLD object.
