## Develop

#### List of Operators

- [`dev_clear_obj`](dev_clear_obj.md) — Delete an iconic object from the HALCON database.

- [`dev_clear_window`](dev_clear_window.md) — Clear the contents of the active graphics window.

- [`dev_close_inspect_ctrl`](dev_close_inspect_ctrl.md) — Close inspect window(s) of one or more control variables.

- [`dev_close_tool`](dev_close_tool.md) — Close the specified floating tool window.

- [`dev_close_window`](dev_close_window.md) — Close the active floating graphics window.

- [`dev_disp_text`](dev_disp_text.md) — Display text in the current graphics window.

- [`dev_display`](dev_display.md) — Displays image objects in the current graphics window.

- [`dev_error_var`](dev_error_var.md) — Define or undefine an error variable.

- [`dev_get_exception_data`](dev_get_exception_data.md) — Access the elements of an exception tuple.

- [`dev_get_preferences`](dev_get_preferences.md) — Query HDevelop preferences within a program.

- [`dev_get_system`](dev_get_system.md) — Query the HDevelop system within a program.

- [`dev_get_window`](dev_get_window.md) — Return the handle of the active graphics window.

- [`dev_inspect_ctrl`](dev_inspect_ctrl.md) — Open a window to inspect one or more control variables.

- [`dev_open_dialog`](dev_open_dialog.md) — Open a modal HDevelop dialog.

- [`dev_open_file_dialog`](dev_open_file_dialog.md) — Opens a file selection dialog.

- [`dev_open_tool`](dev_open_tool.md) — Open a HDevelop tool, a non-modal dialog, or assistant.

- [`dev_open_window`](dev_open_window.md) — Open a new graphics window.

- [`dev_set_check`](dev_set_check.md) — Specify the error handling in HDevelop.

- [`dev_set_color`](dev_set_color.md) — Set one or more output colors.

- [`dev_set_colored`](dev_set_colored.md) — Set multiple output colors.

- [`dev_set_contour_style`](dev_set_contour_style.md) — Define the contour display fill style.

- [`dev_set_draw`](dev_set_draw.md) — Define the region fill mode.

- [`dev_set_line_width`](dev_set_line_width.md) — Define the line width for region contour output.

- [`dev_set_lut`](dev_set_lut.md) — Set “look-up-table” (lut).

- [`dev_set_paint`](dev_set_paint.md) — Define the gray value output mode.

- [`dev_set_part`](dev_set_part.md) — Modify the displayed image part.

- [`dev_set_preferences`](dev_set_preferences.md) — Set HDevelop preferences within a program.

- [`dev_set_shape`](dev_set_shape.md) — Define the region output shape.

- [`dev_set_system`](dev_set_system.md) — Change HDevelop system parameter within a program.

- [`dev_set_tool_geometry`](dev_set_tool_geometry.md) — Sets the position and size of the specified tool.

- [`dev_set_window`](dev_set_window.md) — Activate a graphics window.

- [`dev_set_window_extents`](dev_set_window_extents.md) — Change position and size of the active floating graphics window.

- [`dev_show_tool`](dev_show_tool.md) — Shows the specified tool.

- [`dev_update_pc`](dev_update_pc.md) — Switches the update of the PC during program execution on or off.

- [`dev_update_time`](dev_update_time.md) — Switch time measurement for operators on or off.

- [`dev_update_var`](dev_update_var.md) — Switches the update of the variable window during program execution on or off.

- [`dev_update_window`](dev_update_window.md) — Switches the automatic output of iconic output objects into the graphics
  window during program execution on or off.
