## Tuple

#### List of Operators

- [`deserialize_handle`](deserialize_handle.md) — Deserialize a serialized item.

- [`deserialize_tuple`](deserialize_tuple.md) — Deserialize a serialized tuple.

- [`read_tuple`](read_tuple.md) — Read a tuple from a file.

- [`serialize_handle`](serialize_handle.md) — Serialize the content of a handle.

- [`serialize_tuple`](serialize_tuple.md) — Serialize a tuple.

- [`tuple_is_serializable`](tuple_is_serializable.md) — Test if a tuple is serializable.

- [`tuple_is_serializable_elem`](tuple_is_serializable_elem.md) — Test if the elements of a tuple are serializable.

- [`write_tuple`](write_tuple.md) — Write a tuple to a file.
