## Deformable

#### List of Operators

- [`clear_deformable_model`](clear_deformable_model.md) — Free the memory of a deformable model.

- [`create_local_deformable_model`](create_local_deformable_model.md) — Creates a deformable model for local, deformable matching.

- [`create_local_deformable_model_xld`](create_local_deformable_model_xld.md) — Prepare a deformable model for local deformable matching from XLD contours.

- [`create_planar_calib_deformable_model`](create_planar_calib_deformable_model.md) — Create a deformable model for calibrated perspective matching.

- [`create_planar_calib_deformable_model_xld`](create_planar_calib_deformable_model_xld.md) — Prepare a deformable model for planar calibrated matching from XLD contours.

- [`create_planar_uncalib_deformable_model`](create_planar_uncalib_deformable_model.md) — Creates a deformable model for uncalibrated, perspective matching.

- [`create_planar_uncalib_deformable_model_xld`](create_planar_uncalib_deformable_model_xld.md) — Prepare a deformable model for planar uncalibrated matching
  from XLD contours.

- [`deserialize_deformable_model`](deserialize_deformable_model.md) — Deserialize a deformable model.

- [`determine_deformable_model_params`](determine_deformable_model_params.md) — Determine the parameters of a deformable model.

- [`find_local_deformable_model`](find_local_deformable_model.md) — Find the best matches of a local deformable model in an image.

- [`find_planar_calib_deformable_model`](find_planar_calib_deformable_model.md) — Find the best matches of a calibrated deformable model in an image and return
  their 3D pose.

- [`find_planar_uncalib_deformable_model`](find_planar_uncalib_deformable_model.md) — Find the best matches of a planar projective invariant deformable model
  in an image.

- [`get_deformable_model_contours`](get_deformable_model_contours.md) — Return the contour representation of a deformable model.

- [`get_deformable_model_origin`](get_deformable_model_origin.md) — Return the origin (reference point) of a deformable model.

- [`get_deformable_model_params`](get_deformable_model_params.md) — Return the parameters of a deformable model.

- [`read_deformable_model`](read_deformable_model.md) — Read a deformable model from a file.

- [`serialize_deformable_model`](serialize_deformable_model.md) — Serialize a deformable model.

- [`set_deformable_model_origin`](set_deformable_model_origin.md) — Set the origin (reference point) of a deformable model.

- [`set_deformable_model_param`](set_deformable_model_param.md) — Set selected parameters of the deformable model.

- [`set_local_deformable_model_metric`](set_local_deformable_model_metric.md) — Set the metric of a local deformable model that was created from XLD
  contours.

- [`set_planar_calib_deformable_model_metric`](set_planar_calib_deformable_model_metric.md) — Set the metric of a planar calibrated deformable model that was created
  from XLD contours.

- [`set_planar_uncalib_deformable_model_metric`](set_planar_uncalib_deformable_model_metric.md) — Set the metric of a planar uncalibrated deformable model that was created
  from XLD contours.

- [`write_deformable_model`](write_deformable_model.md) — Write a deformable model to a file.
