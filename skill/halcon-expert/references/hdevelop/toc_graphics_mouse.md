## Mouse

#### List of Operators

- [`get_mbutton`](get_mbutton.md) — Wait until a mouse button is pressed.

- [`get_mbutton_sub_pix`](get_mbutton_sub_pix.md) — Wait until a mouse button is pressed and get the subpixel mouse position.

- [`get_mposition`](get_mposition.md) — Query the mouse position.

- [`get_mposition_sub_pix`](get_mposition_sub_pix.md) — Query the subpixel mouse position.

- [`get_mshape`](get_mshape.md) — Query the current mouse pointer shape.

- [`query_mshape`](query_mshape.md) — Query all available mouse pointer shapes.

- [`send_mouse_double_click_event`](send_mouse_double_click_event.md) — Send an event to a buffer window signaling a mouse double click event.

- [`send_mouse_down_event`](send_mouse_down_event.md) — Send an event to a window buffer signaling a mouse down event.

- [`send_mouse_drag_event`](send_mouse_drag_event.md) — Send an event to a buffer window signaling a mouse drag event.

- [`send_mouse_up_event`](send_mouse_up_event.md) — Send an event to a buffer window signaling a mouse up event.

- [`set_mshape`](set_mshape.md) — Set the current mouse pointer shape.
