## Access

#### List of Operators

- [`close_file`](close_file.md) — Closing a text file.

- [`fnew_line`](fnew_line.md) — Write a line break and clear the output buffer.

- [`fread_bytes`](fread_bytes.md) — Read bytes from a binary file.

- [`fread_char`](fread_char.md) — Read one character from a text file.

- [`fread_line`](fread_line.md) — Read a character line from a text file.

- [`fread_string`](fread_string.md) — Read a string from a text file.

- [`fwrite_bytes`](fwrite_bytes.md) — Write bytes to a binary file.

- [`fwrite_string`](fwrite_string.md) — Write strings and numbers into a text file.

- [`open_file`](open_file.md) — Open a file in text or binary format.
