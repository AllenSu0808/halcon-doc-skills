## Multithreading

#### List of Operators

- [`broadcast_condition`](broadcast_condition.md) — Signal a condition synchronization object.

- [`clear_barrier`](clear_barrier.md) — Destroy a barrier synchronization object.

- [`clear_condition`](clear_condition.md) — Destroy a condition synchronization object.

- [`clear_event`](clear_event.md) — Clear the event synchronization object.

- [`clear_message`](clear_message.md) — Close a message handle and release all associated resources.

- [`clear_message_queue`](clear_message_queue.md) — Close a message queue handle and release all associated resources.

- [`clear_mutex`](clear_mutex.md) — Clear the mutex synchronization object.

- [`create_barrier`](create_barrier.md) — Create a barrier synchronization object.

- [`create_condition`](create_condition.md) — Create a condition variable synchronization object.

- [`create_event`](create_event.md) — Create an event synchronization object.

- [`create_message`](create_message.md) — Create a new empty message.

- [`create_message_queue`](create_message_queue.md) — Create a new empty message queue.

- [`create_mutex`](create_mutex.md) — Create a mutual exclusion synchronization object.

- [`dequeue_message`](dequeue_message.md) — Receive one or more messages from the message queue.

- [`enqueue_message`](enqueue_message.md) — Enqueue one or more messages to the message queue.

- [`get_current_hthread_id`](get_current_hthread_id.md) — Return the HALCON thread ID of the current thread.

- [`get_message_obj`](get_message_obj.md) — Retrieve an object associated with the key from the message.

- [`get_message_param`](get_message_param.md) — Query message parameters or information about the message.

- [`get_message_queue_param`](get_message_queue_param.md) — Query message queue parameters or information about the queue.

- [`get_message_tuple`](get_message_tuple.md) — Retrieve a tuple associated with the key from the message.

- [`get_threading_attrib`](get_threading_attrib.md) — Query the attributes of a threading / synchronization object.

- [`interrupt_operator`](interrupt_operator.md) — Attempt to interrupt an operator running in a different thread.

- [`lock_mutex`](lock_mutex.md) — Lock a mutex synchronization object.

- [`read_message`](read_message.md) — Read a message from a file.

- [`set_message_obj`](set_message_obj.md) — Add a key/object pair to the message.

- [`set_message_param`](set_message_param.md) — Set message parameter or invoke commands on the message.

- [`set_message_queue_param`](set_message_queue_param.md) — Set message queue parameters or invoke commands on the queue.

- [`set_message_tuple`](set_message_tuple.md) — Add a key/tuple pair to the message.

- [`signal_condition`](signal_condition.md) — Signal a condition synchronization object.

- [`signal_event`](signal_event.md) — Unlock an event synchronization object.

- [`timed_wait_condition`](timed_wait_condition.md) — Bounded wait on the signal of a condition synchronization object.

- [`try_lock_mutex`](try_lock_mutex.md) — Lock a mutex synchronization object.

- [`try_wait_event`](try_wait_event.md) — Lock an event synchronization object only if it is unlocked.

- [`unlock_mutex`](unlock_mutex.md) — Unlock a mutex synchronization object.

- [`wait_barrier`](wait_barrier.md) — Wait on the release of a barrier synchronization object.

- [`wait_condition`](wait_condition.md) — wait on the signal of a condition synchronization object.

- [`wait_event`](wait_event.md) — Lock an event synchronization object.

- [`write_message`](write_message.md) — Write a message to a file.
