## Window

#### List of Operators

- [`clear_window`](clear_window.md) — Delete the contents of an output window.

- [`close_window`](close_window.md) — Close an output window.

- [`copy_rectangle`](copy_rectangle.md) — Copy all pixels within rectangles between output windows.

- [`dump_window`](dump_window.md) — Write the window content to a file.

- [`dump_window_image`](dump_window_image.md) — Write the window content in an image object.

- [`flush_buffer`](flush_buffer.md) — Flush the contents of a window.

- [`get_disp_object_model_3d_info`](get_disp_object_model_3d_info.md) — Get the depth or the index of a displayed 3D object model.

- [`get_os_window_handle`](get_os_window_handle.md) — Get the operating system window handle.

- [`get_window_attr`](get_window_attr.md) — Get window characteristics.

- [`get_window_extents`](get_window_extents.md) — Information about a window's size and position.

- [`get_window_pointer3`](get_window_pointer3.md) — Access to a window's pixel data.

- [`get_window_type`](get_window_type.md) — Get the window type.

- [`new_extern_window`](new_extern_window.md) — Create a virtual graphics window under Windows.

- [`open_window`](open_window.md) — Open a graphics window.

- [`query_window_type`](query_window_type.md) — Query all available window types.

- [`set_window_attr`](set_window_attr.md) — Set window characteristics.

- [`set_window_dc`](set_window_dc.md) — Set the device context of a virtual graphics window (Windows NT).

- [`set_window_extents`](set_window_extents.md) — Modify position and size of a window.

- [`set_window_type`](set_window_type.md) — Specify a window type.

- [`unproject_coordinates`](unproject_coordinates.md) — Calculates image coordinates for a point in a 3D plot window.

- [`update_window_pose`](update_window_pose.md) — Modify the pose of a 3D plot.
