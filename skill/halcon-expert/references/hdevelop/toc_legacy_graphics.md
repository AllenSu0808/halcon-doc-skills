## Graphics

#### List of Operators

- [`clear_rectangle`](clear_rectangle.md) — Delete a rectangle on the output window.

- [`disp_distribution`](disp_distribution.md) — Displays a noise distribution.

- [`disp_lut`](disp_lut.md) — Graphical view of the look-up-table (lut).

- [`get_comprise`](get_comprise.md) — Get the output treatment of an image matrix.

- [`get_fix`](get_fix.md) — Get mode of fixing of current look-up-table (lut).

- [`get_fixed_lut`](get_fixed_lut.md) — Get fixing of “look-up-table” (lut) for “real color images”

- [`get_line_approx`](get_line_approx.md) — Get the current approximation error for contour display.

- [`get_lut_style`](get_lut_style.md) — Get modification parameters of look-up-table (lut).

- [`get_pixel`](get_pixel.md) — Get the current color lookup table index.

- [`get_tshape`](get_tshape.md) — Get the shape of the text cursor.

- [`move_rectangle`](move_rectangle.md) — Copy inside an output window.

- [`open_textwindow`](open_textwindow.md) — Open a textual window.

- [`query_tshape`](query_tshape.md) — Query all shapes available for text cursors.

- [`set_comprise`](set_comprise.md) — Define the image matrix output clipping.

- [`set_fix`](set_fix.md) — Set fixing of “look-up-table” (lut)

- [`set_fixed_lut`](set_fixed_lut.md) — Fix “look-up-table” (lut) for “real color images”.

- [`set_line_approx`](set_line_approx.md) — Define the approximation error for contour display.

- [`set_lut_style`](set_lut_style.md) — Changing the look-up-table (lut).

- [`set_pixel`](set_pixel.md) — Define a color lookup table index.

- [`set_tshape`](set_tshape.md) — Set the shape of the text cursor.

- [`slide_image`](slide_image.md) — Interactive output from two window buffers.

- [`write_lut`](write_lut.md) — Write look-up-table (lut) as file.
