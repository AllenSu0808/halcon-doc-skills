## Correlation-Based

#### List of Operators

- [`clear_ncc_model`](clear_ncc_model.md) — Free the memory of an NCC model.

- [`create_ncc_model`](create_ncc_model.md) — Prepare an NCC model for matching.

- [`deserialize_ncc_model`](deserialize_ncc_model.md) — Deserialize an NCC model.

- [`determine_ncc_model_params`](determine_ncc_model_params.md) — Determine the parameters of an NCC model.

- [`find_ncc_model`](find_ncc_model.md) — Find the best matches of an NCC model in an image.

- [`find_ncc_models`](find_ncc_models.md) — Find the best matches of multiple NCC models.

- [`get_ncc_model_origin`](get_ncc_model_origin.md) — Return the origin (reference point) of an NCC model.

- [`get_ncc_model_params`](get_ncc_model_params.md) — Return the parameters of an NCC model.

- [`get_ncc_model_region`](get_ncc_model_region.md) — Return the region used to create an NCC model.

- [`read_ncc_model`](read_ncc_model.md) — Read an NCC model from a file.

- [`serialize_ncc_model`](serialize_ncc_model.md) — Serialize an NCC model.

- [`set_ncc_model_origin`](set_ncc_model_origin.md) — Set the origin (reference point) of an NCC model.

- [`set_ncc_model_param`](set_ncc_model_param.md) — Set selected parameters of the NCC model.

- [`write_ncc_model`](write_ncc_model.md) — Write an NCC model to a file.
