# endif (Operator)

## Name

`endif` — End of if command.

## Signature

`endif( : : : )`

## Description

`endif` is the last statement of an [`if`](if.md), [`elseif`](elseif.md), or
[`else`](else.md) block.

## Result

`endif` always returns 2 (
H_MSG_TRUE)
.
