## Region Growing

#### List of Operators

- [`expand_gray`](expand_gray.md) — Fill gaps between regions (depending on gray value or color) or split
  overlapping regions.

- [`expand_gray_ref`](expand_gray_ref.md) — Fill gaps between regions (depending on gray value or color) or split
  overlapping regions.

- [`regiongrowing`](regiongrowing.md) — Segment an image using region growing.

- [`regiongrowing_mean`](regiongrowing_mean.md) — Perform a region growing using mean gray values.

- [`regiongrowing_n`](regiongrowing_n.md) — Segment an image using region growing for multi-channel images.
