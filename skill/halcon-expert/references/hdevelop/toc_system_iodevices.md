## I/O Devices

#### List of Operators

- [`close_io_channel`](close_io_channel.md) — Close I/O channels.

- [`close_io_device`](close_io_device.md) — Close the specified I/O device.

- [`control_io_channel`](control_io_channel.md) — Perform an action on I/O channels.

- [`control_io_device`](control_io_device.md) — Perform an action on the I/O device.

- [`control_io_interface`](control_io_interface.md) — Perform an action on the I/O interface.

- [`get_io_channel_param`](get_io_channel_param.md) — Query specific parameters of I/O channels.

- [`get_io_device_param`](get_io_device_param.md) — Query settings of an I/O device instance.

- [`open_io_channel`](open_io_channel.md) — Open and configure I/O channels.

- [`open_io_device`](open_io_device.md) — Open and configure an I/O device.

- [`query_io_device`](query_io_device.md) — Query information about channels of the specified I/O device.

- [`query_io_interface`](query_io_interface.md) — Query information about the specified I/O device interface.

- [`read_io_channel`](read_io_channel.md) — Read a value from the specified I/O channels.

- [`set_io_channel_param`](set_io_channel_param.md) — Set specific parameters of I/O channels.

- [`set_io_device_param`](set_io_device_param.md) — Configure a specific I/O device instance.

- [`write_io_channel`](write_io_channel.md) — Write a value to the specified I/O channels.
