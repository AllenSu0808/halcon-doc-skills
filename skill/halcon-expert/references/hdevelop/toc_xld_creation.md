## Creation

#### List of Operators

- [`gen_circle_contour_xld`](gen_circle_contour_xld.md) — Create XLD contours corresponding to circles or circular arcs.

- [`gen_contour_nurbs_xld`](gen_contour_nurbs_xld.md) — Transform a NURBS curve into an XLD contour.

- [`gen_contour_polygon_rounded_xld`](gen_contour_polygon_rounded_xld.md) — Generate an XLD contour with rounded corners from a polygon (given
  as tuples).

- [`gen_contour_polygon_xld`](gen_contour_polygon_xld.md) — Generate an XLD contour from a polygon (given as tuples).

- [`gen_contour_region_xld`](gen_contour_region_xld.md) — Generate XLD contours from regions.

- [`gen_contours_skeleton_xld`](gen_contours_skeleton_xld.md) — Convert a skeleton into XLD contours.

- [`gen_cross_contour_xld`](gen_cross_contour_xld.md) — Generate one XLD contour in the shape of a cross for each input point.

- [`gen_ellipse_contour_xld`](gen_ellipse_contour_xld.md) — Create an XLD contour that corresponds to an elliptic arc.

- [`gen_nurbs_interp`](gen_nurbs_interp.md) — Create control data of a NURBS curve that interpolates given points.

- [`gen_parallels_xld`](gen_parallels_xld.md) — Extract parallel XLD polygons.

- [`gen_polygons_xld`](gen_polygons_xld.md) — Approximate XLD contours by polygons.

- [`gen_rectangle2_contour_xld`](gen_rectangle2_contour_xld.md) — Create an XLD contour in the shape of a rectangle.

- [`mod_parallels_xld`](mod_parallels_xld.md) — Extract parallel XLD polygons enclosing a homogeneous area.
