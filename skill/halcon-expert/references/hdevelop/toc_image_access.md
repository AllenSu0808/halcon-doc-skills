## Access

#### List of Operators

- [`get_grayval`](get_grayval.md) — Access the gray values of an image object.

- [`get_grayval_contour_xld`](get_grayval_contour_xld.md) — Return gray values of an image at the positions of an XLD contour.

- [`get_grayval_interpolated`](get_grayval_interpolated.md) — Return gray values of an image at the positions given by tuples of
  rows and columns.

- [`get_image_pointer1`](get_image_pointer1.md) — Access the pointer of a channel.

- [`get_image_pointer1_rect`](get_image_pointer1_rect.md) — Access to the image data pointer and the image data inside
  the smallest rectangle of the domain of the input image.

- [`get_image_pointer3`](get_image_pointer3.md) — Access the pointers of a colored image.

- [`get_image_size`](get_image_size.md) — Return the size of an image.

- [`get_image_time`](get_image_time.md) — Request time at which the image was created.

- [`get_image_type`](get_image_type.md) — Return the type of an image.
