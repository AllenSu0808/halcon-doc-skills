## Manipulation

#### List of Operators

- [`overpaint_gray`](overpaint_gray.md) — Overpaint the gray values of an image.

- [`overpaint_region`](overpaint_region.md) — Overpaint regions in an image.

- [`paint_gray`](paint_gray.md) — Paint the gray values of an image into another image.

- [`paint_region`](paint_region.md) — Paint regions into an image.

- [`paint_xld`](paint_xld.md) — Paint XLD objects into an image.

- [`set_grayval`](set_grayval.md) — Set single gray values in an image.
