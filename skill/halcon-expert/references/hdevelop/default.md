# default (Operator)

## Name

`default` — Alternative branch in a [`switch`](switch.md) block.

## Signature

`default( : : : )`

## Description

`default` opens an alternative branch in a [`switch`](switch.md) block.
This branch is accessed if the calculated control expression of the
[`switch`](switch.md) statement does not match any of the integer constants
of the previous [`case`](case.md) statements.

## Result

`default` (as an operator) always returns 2 (
H_MSG_TRUE)
.
