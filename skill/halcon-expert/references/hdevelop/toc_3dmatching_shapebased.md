## Shape-Based

#### List of Operators

- [`clear_shape_model_3d`](clear_shape_model_3d.md) — Free the memory of a 3D shape model.

- [`create_cam_pose_look_at_point`](create_cam_pose_look_at_point.md) — Create a 3D camera pose from camera center and viewing direction.

- [`create_shape_model_3d`](create_shape_model_3d.md) — Prepare a 3D object model for matching.

- [`deserialize_shape_model_3d`](deserialize_shape_model_3d.md) — Deserialize a serialized 3D shape model.

- [`find_shape_model_3d`](find_shape_model_3d.md) — Find the best matches of a 3D shape model in an image.

- [`get_shape_model_3d_contours`](get_shape_model_3d_contours.md) — Return the contour representation of a 3D shape model view.

- [`get_shape_model_3d_params`](get_shape_model_3d_params.md) — Return the parameters of a 3D shape model.

- [`project_shape_model_3d`](project_shape_model_3d.md) — Project the edges of a 3D shape model into image coordinates.

- [`read_shape_model_3d`](read_shape_model_3d.md) — Read a 3D shape model from a file.

- [`serialize_shape_model_3d`](serialize_shape_model_3d.md) — Serialize a 3D shape model.

- [`trans_pose_shape_model_3d`](trans_pose_shape_model_3d.md) — Transform a pose that refers to the coordinate system of a 3D object
  model to a pose that refers to the reference coordinate system of a
  3D shape model and vice versa.

- [`write_shape_model_3d`](write_shape_model_3d.md) — Write a 3D shape model to a file.
