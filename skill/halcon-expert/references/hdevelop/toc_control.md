## Control

#### List of Operators

- [`assign`](assign.md) — Assign a new value to a variable.

- [`assign_at`](assign_at.md) — Assignment of one or several values to one or several tuple elements.

- [`break`](break.md) — Terminate loop execution or leave a [`switch`](switch.md) block.

- [`case`](case.md) — Jump label that starts a branch within a [`switch`](switch.md) block.

- [`catch`](catch.md) — Catches exceptions that were thrown in the preceding [`try`](try.md) block.

- [`comment`](comment.md) — Add a comment of one line to the program.

- [`continue`](continue.md) — Skip the current loop execution.

- [`convert_tuple_to_vector_1d`](convert_tuple_to_vector_1d.md) — Distribute the elements of a tuple to a vector.

- [`convert_vector_to_tuple`](convert_vector_to_tuple.md) — Concatenate the elements of a vector to a single tuple.

- [`default`](default.md) — Alternative branch in a [`switch`](switch.md) block.

- [`else`](else.md) — Alternative of conditional statement.

- [`elseif`](elseif.md) — Conditional statement with alternative.

- [`endfor`](endfor.md) — End statement of a for loop.

- [`endif`](endif.md) — End of if command.

- [`endswitch`](endswitch.md) — Ends a multiway branch block.

- [`endtry`](endtry.md) — Ends a block where exceptions are handled.

- [`endwhile`](endwhile.md) — End statement of a while loop.

- [`executable_expression`](executable_expression.md) — Execute a stand-alone operation.

- [`exit`](exit.md) — Terminate HDevelop.

- [`export_def`](export_def.md) — Insert arbitrary text into the export code of a procedure.

- [`for`](for.md) — Starts a loop block that is usually executed for a fixed number of
  iterations.

- [`global`](global.md) — Declare a global variable.

- [`if`](if.md) — Conditional statement.

- [`import`](import.md) — Import one or more external procedures.

- [`insert`](insert.md) — Assignment of a value to a tuple element.

- [`par_join`](par_join.md) — Wait for subthreads that were started with the `par_start`
  qualifier.

- [`repeat`](repeat.md) — Start statement of a repeat..until loop.

- [`return`](return.md) — Terminate procedure call.

- [`stop`](stop.md) — Stop program execution.

- [`switch`](switch.md) — Starts a multiway branch block.

- [`throw`](throw.md) — Throws a user-defined exception or rethrows a caught exception.

- [`try`](try.md) — Starts a program block where exceptions are detected and caught.

- [`until`](until.md) — Continue to execute the body as long as the condition is not true.

- [`while`](while.md) — Starts a loop block that is executed as long as the condition is true.
