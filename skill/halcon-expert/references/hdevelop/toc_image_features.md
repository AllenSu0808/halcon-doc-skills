## Features

#### List of Operators

- [`area_center_gray`](area_center_gray.md) — Compute the area and center of gravity of a region in a gray value
  image.

- [`cooc_feature_image`](cooc_feature_image.md) — Calculate a co-occurrence matrix and derive gray value features thereof.

- [`cooc_feature_matrix`](cooc_feature_matrix.md) — Calculate gray value features from a co-occurrence matrix.

- [`elliptic_axis_gray`](elliptic_axis_gray.md) — Compute the orientation and major axes of a region in a gray value
  image.

- [`entropy_gray`](entropy_gray.md) — Determine the entropy and anisotropy of images.

- [`estimate_noise`](estimate_noise.md) — Estimate the image noise from a single image.

- [`fit_surface_first_order`](fit_surface_first_order.md) — Calculate gray value moments and approximation by a first order surface
  (plane).

- [`fit_surface_second_order`](fit_surface_second_order.md) — Calculate gray value moments and approximation by a second order surface.

- [`fuzzy_entropy`](fuzzy_entropy.md) — Determine the fuzzy entropy of regions.

- [`fuzzy_perimeter`](fuzzy_perimeter.md) — Calculate the fuzzy perimeter of a region.

- [`gen_cooc_matrix`](gen_cooc_matrix.md) — Calculate the co-occurrence matrix of a region in an image.

- [`gray_features`](gray_features.md) — Calculates gray value features for a set of regions.

- [`gray_histo`](gray_histo.md) — Calculate the gray value distribution.

- [`gray_histo_abs`](gray_histo_abs.md) — Calculate the gray value distribution.

- [`gray_histo_range`](gray_histo_range.md) — Calculate the gray value distribution of a single channel image within a
  certain gray value range.

- [`gray_projections`](gray_projections.md) — Calculate horizontal and vertical gray-value projections.

- [`histo_2dim`](histo_2dim.md) — Calculate the histogram of two-channel gray value images.

- [`intensity`](intensity.md) — Calculate the mean and deviation of gray values.

- [`min_max_gray`](min_max_gray.md) — Determine the minimum and maximum gray values within regions.

- [`moments_gray_plane`](moments_gray_plane.md) — Calculate gray value moments and approximation by a plane.

- [`plane_deviation`](plane_deviation.md) — Calculate the deviation of the gray values from the approximating
  image plane.

- [`select_gray`](select_gray.md) — Select regions based on gray value features.

- [`shape_histo_all`](shape_histo_all.md) — Determine a histogram of features along all threshold values.

- [`shape_histo_point`](shape_histo_point.md) — Determine a histogram of features along all threshold values.
