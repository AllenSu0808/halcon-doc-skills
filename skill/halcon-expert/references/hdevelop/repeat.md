# repeat (Operator)

## Name

`repeat` — Start statement of a repeat..until loop.

## Signature

`repeat( : : : )`

## Description

`repeat` is the first statement of an `repeat`..[`until`](until.md)
loop.

## Result

`repeat` always returns 2 (
H_MSG_TRUE)
.

## Alternatives

`for`,
`while`

## See also

`until`,
`break`,
`continue`

Foundation
