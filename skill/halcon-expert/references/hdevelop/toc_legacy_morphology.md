## Morphology

#### List of Operators

- [`closing_golay`](closing_golay.md) — Close a region with an element from the Golay alphabet.

- [`dilation_golay`](dilation_golay.md) — Dilate a region with an element from the Golay alphabet.

- [`dilation_seq`](dilation_seq.md) — Dilate a region sequentially.

- [`erosion_golay`](erosion_golay.md) — Erode a region with an element from the Golay alphabet.

- [`erosion_seq`](erosion_seq.md) — Erode a region sequentially.

- [`fitting`](fitting.md) — Perform a closing after an opening with multiple structuring elements.

- [`gen_struct_elements`](gen_struct_elements.md) — Generate standard structuring elements.

- [`golay_elements`](golay_elements.md) — Generate the structuring elements of the Golay alphabet.

- [`hit_or_miss_golay`](hit_or_miss_golay.md) — Hit-or-miss operation for regions using the Golay alphabet.

- [`hit_or_miss_seq`](hit_or_miss_seq.md) — Hit-or-miss operation for regions using the Golay alphabet (sequential).

- [`morph_hat`](morph_hat.md) — Compute the union of [`bottom_hat`](bottom_hat.md) and [`top_hat`](top_hat.md).

- [`morph_skeleton`](morph_skeleton.md) — Compute the morphological skeleton of a region.

- [`morph_skiz`](morph_skiz.md) — Thinning of a region.

- [`opening_golay`](opening_golay.md) — Open a region with an element from the Golay alphabet.

- [`opening_seg`](opening_seg.md) — Separate overlapping regions.

- [`thickening`](thickening.md) — Add the result of a hit-or-miss operation to a region.

- [`thickening_golay`](thickening_golay.md) — Add the result of a hit-or-miss operation to a region (using a Golay
  structuring element).

- [`thickening_seq`](thickening_seq.md) — Add the result of a hit-or-miss operation to a region (sequential).

- [`thinning`](thinning.md) — Remove the result of a hit-or-miss operation from a region.

- [`thinning_golay`](thinning_golay.md) — Remove the result of a hit-or-miss operation from a region (using a
  Golay structuring element).

- [`thinning_seq`](thinning_seq.md) — Remove the result of a hit-or-miss operation from a region (sequential).
