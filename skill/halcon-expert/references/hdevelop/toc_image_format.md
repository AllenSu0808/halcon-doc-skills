## Format

#### List of Operators

- [`add_image_border`](add_image_border.md) — Add a border to an image.

- [`change_format`](change_format.md) — Change image size.

- [`crop_domain`](crop_domain.md) — Cut out of defined gray values.

- [`crop_domain_rel`](crop_domain_rel.md) — Cut out an image area relative to the domain.

- [`crop_part`](crop_part.md) — Cut out one or more rectangular image areas.

- [`crop_rectangle1`](crop_rectangle1.md) — Cut out one or more rectangular image areas.

- [`crop_rectangle2`](crop_rectangle2.md) — Cut out one or more arbitrarily oriented rectangular image areas.

- [`tile_channels`](tile_channels.md) — Tile multiple images into a large image.

- [`tile_images`](tile_images.md) — Tile multiple image objects into a large image.

- [`tile_images_offset`](tile_images_offset.md) — Tile multiple image objects into a large image with explicit
  positioning information.
