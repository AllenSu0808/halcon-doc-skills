## Edges

#### List of Operators

- [`close_edges`](close_edges.md) — Close edge gaps using the edge amplitude image.

- [`close_edges_length`](close_edges_length.md) — Close edge gaps using the edge amplitude image.

- [`derivate_gauss`](derivate_gauss.md) — Convolve an image with derivatives of the Gaussian.

- [`diff_of_gauss`](diff_of_gauss.md) — Approximate the LoG operator (Laplace of Gaussian).

- [`edges_color`](edges_color.md) — Extract color edges using Canny, Deriche, or Shen filters.

- [`edges_color_sub_pix`](edges_color_sub_pix.md) — Extract subpixel precise color edges using Deriche, Shen, or Canny filters.

- [`edges_image`](edges_image.md) — Extract edges using Deriche, Lanser, Shen, or Canny filters.

- [`edges_sub_pix`](edges_sub_pix.md) — Extract sub-pixel precise edges using Deriche, Lanser, Shen, or Canny
  filters.

- [`frei_amp`](frei_amp.md) — Detect edges (amplitude) using the Frei-Chen operator.

- [`frei_dir`](frei_dir.md) — Detect edges (amplitude and direction) using the Frei-Chen operator.

- [`highpass_image`](highpass_image.md) — Extract high frequency components from an image.

- [`info_edges`](info_edges.md) — Return the filter coefficients of a filter in [`edges_image`](edges_image.md).

- [`kirsch_amp`](kirsch_amp.md) — Detect edges (amplitude) using the Kirsch operator.

- [`kirsch_dir`](kirsch_dir.md) — Detect edges (amplitude and direction) using the Kirsch operator.

- [`laplace`](laplace.md) — Calculate the Laplace operator by using finite differences.

- [`laplace_of_gauss`](laplace_of_gauss.md) — LoG-Operator (Laplace of Gaussian).

- [`prewitt_amp`](prewitt_amp.md) — Detect edges (amplitude) using the Prewitt operator.

- [`prewitt_dir`](prewitt_dir.md) — Detect edges (amplitude and direction) using the Prewitt operator.

- [`roberts`](roberts.md) — Detect edges using the Roberts filter.

- [`robinson_amp`](robinson_amp.md) — Detect edges (amplitude) using the Robinson operator.

- [`robinson_dir`](robinson_dir.md) — Detect edges (amplitude and direction) using the Robinson operator.

- [`sobel_amp`](sobel_amp.md) — Detect edges (amplitude) using the Sobel operator.

- [`sobel_dir`](sobel_dir.md) — Detect edges (amplitude and direction) using the Sobel operator.
