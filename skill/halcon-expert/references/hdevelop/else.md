# else (Operator)

## Name

`else` — Alternative of conditional statement.

## Signature

`else( : : : )`

## Description

`else` continues after an [`if`](if.md) or [`elseif`](elseif.md) block with
an alternative block.
If the conditions of all corresponding [`if`](if.md) or [`elseif`](elseif.md) blocks
evaluated to *'false'* (*0*), i.e., none of the corresponding
[`if`](if.md) or [`elseif`](elseif.md) blocks has been executed, the following
`else` block is executed.

## Result

`else` (as operator) always returns 2 (
H_MSG_TRUE)
.

## Alternatives

`if`,
`elseif`
