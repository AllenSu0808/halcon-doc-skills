## Information

#### List of Operators

- [`get_chapter_info`](get_chapter_info.md) — Get information concerning the chapters on operators.

- [`get_keywords`](get_keywords.md) — Get keywords which are assigned to operators.

- [`get_operator_info`](get_operator_info.md) — Get information concerning a HALCON-operator.

- [`get_operator_name`](get_operator_name.md) — Get operators with the given string as a substring of their name.

- [`get_param_info`](get_param_info.md) — Get information concerning the operator parameters.

- [`get_param_names`](get_param_names.md) — Get the names of the parameters of a HALCON-operator.

- [`get_param_num`](get_param_num.md) — Get number of the different parameter classes of a HALCON-operator.

- [`get_param_types`](get_param_types.md) — Get default data type for the control parameters of a HALCON-operator.

- [`query_operator_info`](query_operator_info.md) — Query slots concerning information with relation to the operator [`get_operator_info`](get_operator_info.md).

- [`query_param_info`](query_param_info.md) — Query slots of the online-information concerning the operator [`get_param_info`](get_param_info.md).

- [`search_operator`](search_operator.md) — Search names of all operators assigned to one keyword.
