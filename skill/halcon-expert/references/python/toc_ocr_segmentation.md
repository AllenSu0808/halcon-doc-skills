## Segmentation

#### List of Operators

- [`clear_text_model`](clear_text_model.md) — Clear a text model.

- [`clear_text_result`](clear_text_result.md) — Clear a text result.

- [`create_text_model_reader`](create_text_model_reader.md) — Create a text model.

- [`find_text`](find_text.md) — Find text in an image.

- [`get_text_model_param`](get_text_model_param.md) — Query parameters of a text model.

- [`get_text_object`](get_text_object.md) — Query an iconic value of a text segmentation result.

- [`get_text_result`](get_text_result.md) — Query a control value of a text segmentation result.

- [`segment_characters`](segment_characters.md) — Segments characters in a given region of an image.

- [`select_characters`](select_characters.md) — Selects characters from a given region.

- [`set_text_model_param`](set_text_model_param.md) — Set parameters of a text model.

- [`text_line_orientation`](text_line_orientation.md) — Determines the orientation of a text line or paragraph.

- [`text_line_slant`](text_line_slant.md) — Determines the slant of characters of a text line or paragraph.
