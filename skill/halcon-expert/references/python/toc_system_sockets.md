## Sockets

#### List of Operators

- [`close_socket`](close_socket.md) — Close a socket.

- [`get_next_socket_data_type`](get_next_socket_data_type.md) — Determine the HALCON data type of the next socket data.

- [`get_socket_descriptor`](get_socket_descriptor.md) — Get the socket descriptor of a socket used by the operating system.

- [`get_socket_param`](get_socket_param.md) — Get the value of a socket parameter.

- [`open_socket_accept`](open_socket_accept.md) — Open a socket that accepts connection requests.

- [`open_socket_connect`](open_socket_connect.md) — Open a socket and connect it to an accepting socket.

- [`receive_data`](receive_data.md) — Receive arbitrary data from external devices or applications using a
  generic socket connection.

- [`receive_image`](receive_image.md) — Receive an image over a socket connection.

- [`receive_region`](receive_region.md) — Receive regions over a socket connection.

- [`receive_serialized_item`](receive_serialized_item.md) — Receive a serialized item over a socket connection.

- [`receive_tuple`](receive_tuple.md) — Receive a tuple over a socket connection.

- [`receive_xld`](receive_xld.md) — Receive an XLD object over a socket connection.

- [`send_data`](send_data.md) — Send arbitrary data to external devices or applications using a
  generic socket communication.

- [`send_image`](send_image.md) — Send an image over a socket connection.

- [`send_region`](send_region.md) — Send regions over a socket connection.

- [`send_serialized_item`](send_serialized_item.md) — Send a serialized item over a socket connection.

- [`send_tuple`](send_tuple.md) — Send a tuple over a socket connection.

- [`send_xld`](send_xld.md) — Send an XLD object over a socket connection.

- [`set_socket_param`](set_socket_param.md) — Set a socket parameter.

- [`socket_accept_connect`](socket_accept_connect.md) — Accept a connection request on a listening socket of the protocol type
  *`"HALCON"`* or *`"TCP"`*/*`"TCP4"`*/*`"TCP6"`*.
