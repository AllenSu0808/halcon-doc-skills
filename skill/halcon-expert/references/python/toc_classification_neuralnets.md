## Neural Nets

#### List of Operators

- [`add_class_train_data_mlp`](add_class_train_data_mlp.md) — Add training data to a multilayer perceptron (MLP).

- [`add_sample_class_mlp`](add_sample_class_mlp.md) — Add a training sample to the training data of a multilayer
  perceptron.

- [`classify_class_mlp`](classify_class_mlp.md) — Calculate the class of a feature vector by a multilayer perceptron.

- [`clear_class_mlp`](clear_class_mlp.md) — Clear a multilayer perceptron.

- [`clear_samples_class_mlp`](clear_samples_class_mlp.md) — Clear the training data of a multilayer perceptron.

- [`create_class_mlp`](create_class_mlp.md) — Create a multilayer perceptron for classification or regression.

- [`deserialize_class_mlp`](deserialize_class_mlp.md) — Deserialize a serialized multilayer perceptron.

- [`evaluate_class_mlp`](evaluate_class_mlp.md) — Calculate the evaluation of a feature vector by a multilayer
  perceptron.

- [`get_class_train_data_mlp`](get_class_train_data_mlp.md) — Get the training data of a multilayer perceptron (MLP).

- [`get_params_class_mlp`](get_params_class_mlp.md) — Return the parameters of a multilayer perceptron.

- [`get_prep_info_class_mlp`](get_prep_info_class_mlp.md) — Compute the information content of the preprocessed feature vectors
  of a multilayer perceptron.

- [`get_regularization_params_class_mlp`](get_regularization_params_class_mlp.md) — Return the regularization parameters of a multilayer perceptron.

- [`get_rejection_params_class_mlp`](get_rejection_params_class_mlp.md) — Get the parameters of a rejection class.

- [`get_sample_class_mlp`](get_sample_class_mlp.md) — Return a training sample from the training data of a multilayer
  perceptron.

- [`get_sample_num_class_mlp`](get_sample_num_class_mlp.md) — Return the number of training samples stored in the training data of
  a multilayer perceptron.

- [`read_class_mlp`](read_class_mlp.md) — Read a multilayer perceptron from a file.

- [`read_samples_class_mlp`](read_samples_class_mlp.md) — Read the training data of a multilayer perceptron from a file.

- [`select_feature_set_mlp`](select_feature_set_mlp.md) — Selects an optimal combination of features to classify the provided data.

- [`serialize_class_mlp`](serialize_class_mlp.md) — Serialize a multilayer perceptron (MLP).

- [`set_regularization_params_class_mlp`](set_regularization_params_class_mlp.md) — Set the regularization parameters of a multilayer perceptron.

- [`set_rejection_params_class_mlp`](set_rejection_params_class_mlp.md) — Set the parameters of a rejection class.

- [`train_class_mlp`](train_class_mlp.md) — Train a multilayer perceptron.

- [`write_class_mlp`](write_class_mlp.md) — Write a multilayer perceptron to a file.

- [`write_samples_class_mlp`](write_samples_class_mlp.md) — Write the training data of a multilayer perceptron to a file.
