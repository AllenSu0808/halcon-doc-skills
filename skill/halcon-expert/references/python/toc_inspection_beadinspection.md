## Bead Inspection

#### List of Operators

- [`apply_bead_inspection_model`](apply_bead_inspection_model.md) — Inspect beads in an image, as defined by the bead inspection
  model.

- [`clear_bead_inspection_model`](clear_bead_inspection_model.md) — Delete the bead inspection model and free the allocated memory.

- [`create_bead_inspection_model`](create_bead_inspection_model.md) — Create a model to inspect beads or adhesive in images.

- [`get_bead_inspection_param`](get_bead_inspection_param.md) — Get the value of a parameter in a specific bead inspection model.

- [`set_bead_inspection_param`](set_bead_inspection_param.md) — Set parameters of the bead inspection model.
