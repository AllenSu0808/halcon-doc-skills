## OCR

#### List of Operators

- [`close_ocr`](close_ocr.md) — Deallocation of the memory of an OCR classifier.

- [`create_ocr_class_box`](create_ocr_class_box.md) — Create a new OCR-classifier.

- [`create_text_model`](create_text_model.md) — Create a text model.

- [`deserialize_ocr`](deserialize_ocr.md) — Deserialize a serialized OCR classifier.

- [`do_ocr_multi`](do_ocr_multi.md) — Classify characters.

- [`do_ocr_single`](do_ocr_single.md) — Classify one character.

- [`ocr_change_char`](ocr_change_char.md) — Define a new conversion table for the characters.

- [`ocr_get_features`](ocr_get_features.md) — Access the features which correspond to a character.

- [`read_ocr`](read_ocr.md) — Read an OCR classifier from a file.

- [`serialize_ocr`](serialize_ocr.md) — Serialize an OCR classifier.

- [`testd_ocr_class_box`](testd_ocr_class_box.md) — Test an OCR classifier.

- [`traind_ocr_class_box`](traind_ocr_class_box.md) — Train an OCR classifier by the input of regions.

- [`trainf_ocr_class_box`](trainf_ocr_class_box.md) — Train an OCR classifier with the help of a training file.

- [`write_ocr`](write_ocr.md) — Writing an OCR classifier into a file.
