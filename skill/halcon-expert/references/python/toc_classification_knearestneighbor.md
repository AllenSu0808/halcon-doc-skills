## K-Nearest Neighbors

#### List of Operators

- [`add_class_train_data_knn`](add_class_train_data_knn.md) — Add training data to a k-nearest neighbors (k-NN) classifier.

- [`add_sample_class_knn`](add_sample_class_knn.md) — Add a sample to a k-nearest neighbors (k-NN) classifier.

- [`classify_class_knn`](classify_class_knn.md) — Search for the next neighbors for a given feature vector.

- [`clear_class_knn`](clear_class_knn.md) — Clear a k-NN classifier.

- [`create_class_knn`](create_class_knn.md) — Create a k-nearest neighbors (k-NN) classifier.

- [`deserialize_class_knn`](deserialize_class_knn.md) — Deserialize a serialized k-NN classifier.

- [`get_class_train_data_knn`](get_class_train_data_knn.md) — Get the training data of a k-nearest neighbors (k-NN) classifier.

- [`get_params_class_knn`](get_params_class_knn.md) — Get parameters of a k-NN classification.

- [`get_sample_class_knn`](get_sample_class_knn.md) — Return a training sample from the training data of a k-nearest neighbors
  (k-NN) classifier.

- [`get_sample_num_class_knn`](get_sample_num_class_knn.md) — Return the number of training samples stored in the training data of
  a k-nearest neighbors (k-NN) classifier.

- [`read_class_knn`](read_class_knn.md) — Read the k-NN classifier from a file.

- [`select_feature_set_knn`](select_feature_set_knn.md) — Selects an optimal subset from a set of features to solve a certain
  classification problem.

- [`serialize_class_knn`](serialize_class_knn.md) — Serialize a k-NN classifier.

- [`set_params_class_knn`](set_params_class_knn.md) — Set parameters for k-NN classification.

- [`train_class_knn`](train_class_knn.md) — Creates the search trees for a k-NN classifier.

- [`write_class_knn`](write_class_knn.md) — Save the k-NN classifier in a file.
