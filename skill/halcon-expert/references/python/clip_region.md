# clip_region (Operator)

## Name

`clip_region` — Clip a region to a rectangle.

## Signature

`def clip_region(region: HObject, row_1: int, column_1: int, row_2: int, column_2: int) -> HObject`

## Description

`clip_region` clips the input regions to the rectangle
given by the four control parameters. `clip_region` is
more efficient than calling [`intersection`](intersection.md) with a
rectangle generated by [`gen_rectangle1`](gen_rectangle1.md).

## Execution Information

- Multithreading type: reentrant (runs in parallel with non-exclusive operators).
- Multithreading scope: global (may be called from any thread).
- Automatically parallelized on tuple level.

## Result

`clip_region` returns 2 (
H_MSG_TRUE)
if all parameters are correct.
The behavior in case of empty input (no regions given) can be set
via `set_system('no_object_result',<Result>)`
and the behavior in case of an empty input region via
`set_system('empty_region_result',<Result>)`.
If necessary, an exception is raised.
