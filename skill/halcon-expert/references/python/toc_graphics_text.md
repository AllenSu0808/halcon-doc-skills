## Text

#### List of Operators

- [`disp_text`](disp_text.md) — Display text in a window.

- [`get_font`](get_font.md) — Get the current font.

- [`get_font_extents`](get_font_extents.md) — Get the maximum size of all characters of a font.

- [`get_string_extents`](get_string_extents.md) — Get the spatial size of a string.

- [`get_tposition`](get_tposition.md) — Get cursor position.

- [`new_line`](new_line.md) — Set the position of the text cursor to the beginning of the next line.

- [`query_font`](query_font.md) — Query the available fonts.

- [`read_char`](read_char.md) — Read a character from a window.

- [`read_string`](read_string.md) — Read a string in a text window.

- [`set_font`](set_font.md) — Set the font used for text output.

- [`set_tposition`](set_tposition.md) — Set the position of the text cursor.

- [`write_string`](write_string.md) — Print text in a window.
