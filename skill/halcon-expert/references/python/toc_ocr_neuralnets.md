## Neural Nets

#### List of Operators

- [`clear_ocr_class_mlp`](clear_ocr_class_mlp.md) — Clear an OCR classifier.

- [`create_ocr_class_mlp`](create_ocr_class_mlp.md) — Create an OCR classifier using a multilayer perceptron.

- [`deserialize_ocr_class_mlp`](deserialize_ocr_class_mlp.md) — Deserialize a serialized MLP-based OCR classifier.

- [`do_ocr_multi_class_mlp`](do_ocr_multi_class_mlp.md) — Classify multiple characters with an OCR classifier.

- [`do_ocr_single_class_mlp`](do_ocr_single_class_mlp.md) — Classify a single character with an OCR classifier.

- [`do_ocr_word_mlp`](do_ocr_word_mlp.md) — Classify a related group of characters with an OCR classifier.

- [`get_features_ocr_class_mlp`](get_features_ocr_class_mlp.md) — Compute the features of a character.

- [`get_params_ocr_class_mlp`](get_params_ocr_class_mlp.md) — Return the parameters of an OCR classifier.

- [`get_prep_info_ocr_class_mlp`](get_prep_info_ocr_class_mlp.md) — Compute the information content of the preprocessed feature vectors
  of an OCR classifier.

- [`get_regularization_params_ocr_class_mlp`](get_regularization_params_ocr_class_mlp.md) — Return the regularization parameters of an OCR classifier.

- [`get_rejection_params_ocr_class_mlp`](get_rejection_params_ocr_class_mlp.md) — Return the rejection class parameters of an OCR classifier.

- [`read_ocr_class_mlp`](read_ocr_class_mlp.md) — Read an OCR classifier from a file.

- [`select_feature_set_trainf_mlp`](select_feature_set_trainf_mlp.md) — Selects an optimal combination of features to classify OCR data.

- [`select_feature_set_trainf_mlp_protected`](select_feature_set_trainf_mlp_protected.md) — Select an optimal combination of features to classify OCR data
  from a (protected) training file.

- [`serialize_ocr_class_mlp`](serialize_ocr_class_mlp.md) — Serialize a MLP-based OCR classifier.

- [`set_regularization_params_ocr_class_mlp`](set_regularization_params_ocr_class_mlp.md) — Set the regularization parameters of an OCR classifier.

- [`set_rejection_params_ocr_class_mlp`](set_rejection_params_ocr_class_mlp.md) — Set the rejection class parameters of an OCR classifier.

- [`trainf_ocr_class_mlp`](trainf_ocr_class_mlp.md) — Train an OCR classifier.

- [`trainf_ocr_class_mlp_protected`](trainf_ocr_class_mlp_protected.md) — Train an OCR classifier with data from a (protected) training file.

- [`write_ocr_class_mlp`](write_ocr_class_mlp.md) — Write an OCR classifier to a file.
