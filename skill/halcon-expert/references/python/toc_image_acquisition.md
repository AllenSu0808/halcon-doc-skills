## Acquisition

#### List of Operators

- [`close_framegrabber`](close_framegrabber.md) — Close specified image acquisition device.

- [`get_framegrabber_callback`](get_framegrabber_callback.md) — Query callback function of an image acquisition device.

- [`get_framegrabber_lut`](get_framegrabber_lut.md) — Query look-up table of the image acquisition device.

- [`get_framegrabber_param`](get_framegrabber_param.md) — Query specific parameters of an image acquisition device.

- [`grab_data`](grab_data.md) — Synchronous grab of images and preprocessed image data from the specified
  image acquisition device.

- [`grab_data_async`](grab_data_async.md) — Asynchronous grab of images and preprocessed image data from the specified
  image acquisition device.

- [`grab_image`](grab_image.md) — Synchronous grab of an image from the specified image acquisition device.

- [`grab_image_async`](grab_image_async.md) — Asynchronous grab of an image from the specified image acquisition device.

- [`grab_image_start`](grab_image_start.md) — Start an asynchronous grab from the specified image acquisition device.

- [`info_framegrabber`](info_framegrabber.md) — Query information about the specified image acquisition interface.

- [`open_framegrabber`](open_framegrabber.md) — Open and configure an image acquisition device.

- [`set_framegrabber_callback`](set_framegrabber_callback.md) — Register a callback function for an image acquisition device.

- [`set_framegrabber_lut`](set_framegrabber_lut.md) — Set look-up table of the image acquisition device.

- [`set_framegrabber_param`](set_framegrabber_param.md) — Set specific parameters of an image acquisition device.
