## Matching, Component-Based

#### List of Operators

- [`clear_component_model`](clear_component_model.md) — Free the memory of a component model.

- [`clear_training_components`](clear_training_components.md) — Free the memory of a component training result.

- [`cluster_model_components`](cluster_model_components.md) — Adopt new parameters that are used to create the model components into the
  training result.

- [`create_component_model`](create_component_model.md) — Prepare a component model for matching based on explicitly specified
  components and relations.

- [`create_trained_component_model`](create_trained_component_model.md) — Prepare a component model for matching based on trained components.

- [`deserialize_component_model`](deserialize_component_model.md) — Deserialize a serialized component model.

- [`deserialize_training_components`](deserialize_training_components.md) — Deserialize a component training result.

- [`find_component_model`](find_component_model.md) — Find the best matches of a component model in an image.

- [`gen_initial_components`](gen_initial_components.md) — Extract the initial components of a component model.

- [`get_component_model_params`](get_component_model_params.md) — Return the parameters of a component model.

- [`get_component_model_tree`](get_component_model_tree.md) — Return the search tree of a component model.

- [`get_component_relations`](get_component_relations.md) — Return the relations between the model components that are contained in
  a training result.

- [`get_found_component_model`](get_found_component_model.md) — Return the components of a found instance of a component model.

- [`get_training_components`](get_training_components.md) — Return the initial or model components in a certain image.

- [`inspect_clustered_components`](inspect_clustered_components.md) — Inspect the rigid model components obtained from the training.

- [`modify_component_relations`](modify_component_relations.md) — Modify the relations within a training result.

- [`read_component_model`](read_component_model.md) — Read a component model from a file.

- [`read_training_components`](read_training_components.md) — Read a component training result from a file.

- [`serialize_component_model`](serialize_component_model.md) — Serialize a component model.

- [`serialize_training_components`](serialize_training_components.md) — Serialize a component training result.

- [`train_model_components`](train_model_components.md) — Train components and relations for the component-based matching.

- [`write_component_model`](write_component_model.md) — Write a component model to a file.

- [`write_training_components`](write_training_components.md) — Write a component training result to a file.
