## Features

#### List of Operators

- [`area_object_model_3d`](area_object_model_3d.md) — Calculate the area of all faces of a 3D object model.

- [`distance_object_model_3d`](distance_object_model_3d.md) — Compute the distances of the points of one 3D object model to another
  3D object model.

- [`get_object_model_3d_params`](get_object_model_3d_params.md) — Return attributes of 3D object models.

- [`max_diameter_object_model_3d`](max_diameter_object_model_3d.md) — Calculate the maximal diameter of a 3D object model.

- [`moments_object_model_3d`](moments_object_model_3d.md) — Calculates the mean or the central moment of second order for a 3D object
  model.

- [`select_object_model_3d`](select_object_model_3d.md) — Select 3D object models from an array of 3D object models according
  to global features.

- [`smallest_bounding_box_object_model_3d`](smallest_bounding_box_object_model_3d.md) — Calculate the smallest bounding box around the points of a
  3D object model.

- [`smallest_sphere_object_model_3d`](smallest_sphere_object_model_3d.md) — Calculate the smallest sphere around the points of a 3D object model.

- [`volume_object_model_3d_relative_to_plane`](volume_object_model_3d_relative_to_plane.md) — Calculate the volume of a 3D object model.
