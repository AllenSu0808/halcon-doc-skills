## Data Containers

#### List of Operators

- [`copy_dict`](copy_dict.md) — Copy a dictionary.

- [`create_dict`](create_dict.md) — Create a new empty dictionary.

- [`dict_to_json`](dict_to_json.md) — Transform a dictionary into a JSON string.

- [`get_dict_object`](get_dict_object.md) — Retrieve an object associated with the key from the dictionary.

- [`get_dict_param`](get_dict_param.md) — Query dictionary parameters or information about a dictionary.

- [`get_dict_tuple`](get_dict_tuple.md) — Retrieve a tuple associated with the key from the dictionary.

- [`json_to_dict`](json_to_dict.md) — Transform a JSON string into a dictionary.

- [`read_dict`](read_dict.md) — Read a dictionary from a file.

- [`remove_dict_key`](remove_dict_key.md) — Remove keys from a dictionary.

- [`set_dict_object`](set_dict_object.md) — Add a key/object pair to the dictionary.

- [`set_dict_tuple`](set_dict_tuple.md) — Add a key/tuple pair to the dictionary.

- [`set_dict_tuple_at`](set_dict_tuple_at.md) — Assignment of one or several values to one or several tuple elements
  in a dictionary

- [`write_dict`](write_dict.md) — Write a dictionary to a file.
