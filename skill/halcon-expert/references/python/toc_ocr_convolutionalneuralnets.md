## Convolutional Neural Networks

#### List of Operators

- [`clear_ocr_class_cnn`](clear_ocr_class_cnn.md) — Clear an CNN-based OCR classifier.

- [`deserialize_ocr_class_cnn`](deserialize_ocr_class_cnn.md) — Deserialize a serialized CNN-based OCR classifier.

- [`do_ocr_multi_class_cnn`](do_ocr_multi_class_cnn.md) — Classify multiple characters with an CNN-based OCR classifier.

- [`do_ocr_single_class_cnn`](do_ocr_single_class_cnn.md) — Classify a single character with an CNN-based OCR classifier.

- [`do_ocr_word_cnn`](do_ocr_word_cnn.md) — Classify a related group of characters with an CNN-based OCR classifier.

- [`get_params_ocr_class_cnn`](get_params_ocr_class_cnn.md) — Return the parameters of a CNN-based OCR classifier.

- [`query_params_ocr_class_cnn`](query_params_ocr_class_cnn.md) — Get the names of the parameters that can be used in
  [`get_params_ocr_class_cnn`](get_params_ocr_class_cnn.md)
  for a given CNN-based OCR classifier.

- [`read_ocr_class_cnn`](read_ocr_class_cnn.md) — Read an CNN-based OCR classifier from a file.

- [`serialize_ocr_class_cnn`](serialize_ocr_class_cnn.md) — Serialize a CNN-based OCR classifier
