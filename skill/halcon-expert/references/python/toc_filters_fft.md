## FFT

#### List of Operators

- [`convol_fft`](convol_fft.md) — Multiply an image with a filter image in the frequency domain.

- [`convol_gabor`](convol_gabor.md) — Convolve an image with a Gabor filter in the frequency domain.

- [`correlation_fft`](correlation_fft.md) — Multiply one image with the complex conjugate of another image in the
  frequency domain.

- [`deserialize_fft_optimization_data`](deserialize_fft_optimization_data.md) — Deserialize FFT speed optimization data.

- [`energy_gabor`](energy_gabor.md) — Calculate the energy of a two-channel image.

- [`fft_generic`](fft_generic.md) — Compute the fast Fourier transform of an image.

- [`fft_image`](fft_image.md) — Compute the fast Fourier transform of an image.

- [`fft_image_inv`](fft_image_inv.md) — Compute the inverse fast Fourier transform of an image.

- [`gen_bandfilter`](gen_bandfilter.md) — Generate an ideal band filter.

- [`gen_bandpass`](gen_bandpass.md) — Generate an ideal bandpass filter.

- [`gen_derivative_filter`](gen_derivative_filter.md) — Generate a derivative filter in the frequency domain.

- [`gen_filter_mask`](gen_filter_mask.md) — Store a filter mask in the spatial domain as a real-image.

- [`gen_gabor`](gen_gabor.md) — Generate a Gabor filter.

- [`gen_gauss_filter`](gen_gauss_filter.md) — Generate a Gaussian filter in the frequency domain.

- [`gen_highpass`](gen_highpass.md) — Generate an ideal highpass filter.

- [`gen_lowpass`](gen_lowpass.md) — Generate an ideal lowpass filter.

- [`gen_mean_filter`](gen_mean_filter.md) — Generate a mean filter in the frequency domain.

- [`gen_sin_bandpass`](gen_sin_bandpass.md) — Generate a bandpass filter with sinusoidal shape.

- [`gen_std_bandpass`](gen_std_bandpass.md) — Generate a bandpass filter with Gaussian or sinusoidal shape.

- [`optimize_fft_speed`](optimize_fft_speed.md) — Optimize the runtime of the FFT.

- [`optimize_rft_speed`](optimize_rft_speed.md) — Optimize the runtime of the real-valued FFT.

- [`phase_correlation_fft`](phase_correlation_fft.md) — Compute the phase correlation of two images in the frequency domain.

- [`phase_deg`](phase_deg.md) — Return the phase of a complex image in degrees.

- [`phase_rad`](phase_rad.md) — Return the phase of a complex image in radians.

- [`power_byte`](power_byte.md) — Return the power spectrum of a complex image.

- [`power_ln`](power_ln.md) — Return the power spectrum of a complex image.

- [`power_real`](power_real.md) — Return the power spectrum of a complex image.

- [`read_fft_optimization_data`](read_fft_optimization_data.md) — Load FFT speed optimization data from a file.

- [`rft_generic`](rft_generic.md) — Compute the real-valued fast Fourier transform of an image.

- [`serialize_fft_optimization_data`](serialize_fft_optimization_data.md) — Serialize FFT speed optimization data.

- [`write_fft_optimization_data`](write_fft_optimization_data.md) — Store FFT speed optimization data in a file.
