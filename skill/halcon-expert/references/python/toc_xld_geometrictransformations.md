## Geometric Transformations

#### List of Operators

- [`affine_trans_contour_xld`](affine_trans_contour_xld.md) — Apply an arbitrary affine 2D transformation to XLD contours.

- [`affine_trans_polygon_xld`](affine_trans_polygon_xld.md) — Apply an arbitrary affine transformation to XLD polygons.

- [`gen_parallel_contour_xld`](gen_parallel_contour_xld.md) — Compute the parallel contour of an XLD contour.

- [`polar_trans_contour_xld`](polar_trans_contour_xld.md) — Transform a contour in an annular arc to polar coordinates.

- [`polar_trans_contour_xld_inv`](polar_trans_contour_xld_inv.md) — Transform a contour in polar coordinates back to Cartesian coordinates

- [`projective_trans_contour_xld`](projective_trans_contour_xld.md) — Apply a projective transformation to an XLD contour.
