## Access

#### List of Operators

- [`get_diagonal_matrix`](get_diagonal_matrix.md) — Get the diagonal elements of a matrix.

- [`get_full_matrix`](get_full_matrix.md) — Return all values of a matrix.

- [`get_sub_matrix`](get_sub_matrix.md) — Get a sub-matrix of a matrix.

- [`get_value_matrix`](get_value_matrix.md) — Return one ore more elements of a matrix.

- [`set_diagonal_matrix`](set_diagonal_matrix.md) — Set the diagonal elements of a matrix.

- [`set_full_matrix`](set_full_matrix.md) — Set all values of a matrix.

- [`set_sub_matrix`](set_sub_matrix.md) — Set a sub-matrix of a matrix.

- [`set_value_matrix`](set_value_matrix.md) — Set one or more elements of a matrix.
