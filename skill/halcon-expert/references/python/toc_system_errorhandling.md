## Error Handling

#### List of Operators

- [`get_check`](get_check.md) — State of the HALCON control modes.

- [`get_error_text`](get_error_text.md) — Inquiry after the error text of a HALCON error number.

- [`get_extended_error_info`](get_extended_error_info.md) — Returns the extended error information for the calling thread's last
  HALCON error.

- [`get_spy`](get_spy.md) — Current configuration of the HALCON debugging-tool.

- [`query_spy`](query_spy.md) — Inquiring for possible settings of the HALCON debugging tool.

- [`set_check`](set_check.md) — Activating and deactivating of HALCON control modes.

- [`set_spy`](set_spy.md) — Control of the HALCON Debugging Tools.
