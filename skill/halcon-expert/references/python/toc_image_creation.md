## Creation

#### List of Operators

- [`copy_image`](copy_image.md) — Copy an image and allocate new memory for it.

- [`gen_image1`](gen_image1.md) — Create an image from a pointer to the pixels.

- [`gen_image1_extern`](gen_image1_extern.md) — Create an image from a pointer on the pixels with storage management.

- [`gen_image1_rect`](gen_image1_rect.md) — Create an image with a rectangular domain from a pointer on the pixels
  (with storage management).

- [`gen_image3`](gen_image3.md) — Create an image from three pointers to the pixels (red/green/blue).

- [`gen_image3_extern`](gen_image3_extern.md) — Create a three-channel image from three pointers on the pixels with storage
  management.

- [`gen_image_const`](gen_image_const.md) — Create an image with constant gray value.

- [`gen_image_gray_ramp`](gen_image_gray_ramp.md) — Create a gray value ramp.

- [`gen_image_interleaved`](gen_image_interleaved.md) — Create a three-channel image from a pointer to the interleaved pixels.

- [`gen_image_proto`](gen_image_proto.md) — Create an image with a specified constant gray value.

- [`gen_image_surface_first_order`](gen_image_surface_first_order.md) — Create a tilted gray surface with first order polynomial.

- [`gen_image_surface_second_order`](gen_image_surface_second_order.md) — Create a curved gray surface with second order polynomial.

- [`interleave_channels`](interleave_channels.md) — Create an interleaved image from a multichannel image.

- [`region_to_bin`](region_to_bin.md) — Convert a region into a binary byte-image.

- [`region_to_label`](region_to_label.md) — Convert regions to a label image.

- [`region_to_mean`](region_to_mean.md) — Paint regions with their average gray value.
