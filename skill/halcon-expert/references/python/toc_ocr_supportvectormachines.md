## Support Vector Machines

#### List of Operators

- [`clear_ocr_class_svm`](clear_ocr_class_svm.md) — Clear an SVM-based OCR classifier.

- [`create_ocr_class_svm`](create_ocr_class_svm.md) — Create an OCR classifier using a support vector machine.

- [`deserialize_ocr_class_svm`](deserialize_ocr_class_svm.md) — Deserialize a serialized SVM-based OCR classifier.

- [`do_ocr_multi_class_svm`](do_ocr_multi_class_svm.md) — Classify multiple characters with an SVM-based OCR classifier.

- [`do_ocr_single_class_svm`](do_ocr_single_class_svm.md) — Classify a single character with an SVM-based OCR classifier.

- [`do_ocr_word_svm`](do_ocr_word_svm.md) — Classify a related group of characters with an OCR classifier.

- [`get_features_ocr_class_svm`](get_features_ocr_class_svm.md) — Compute the features of a character.

- [`get_params_ocr_class_svm`](get_params_ocr_class_svm.md) — Return the parameters of an OCR classifier.

- [`get_prep_info_ocr_class_svm`](get_prep_info_ocr_class_svm.md) — Compute the information content of the preprocessed feature vectors
  of an SVM-based OCR classifier.

- [`get_support_vector_num_ocr_class_svm`](get_support_vector_num_ocr_class_svm.md) — Return the number of support vectors of an OCR classifier.

- [`get_support_vector_ocr_class_svm`](get_support_vector_ocr_class_svm.md) — Return the index of a support vector from a trained OCR classifier that is
  based on support vector machines.

- [`read_ocr_class_svm`](read_ocr_class_svm.md) — Read a SVM-based OCR classifier from a file.

- [`reduce_ocr_class_svm`](reduce_ocr_class_svm.md) — Approximate a trained SVM-based OCR classifier by a reduced SVM.

- [`select_feature_set_trainf_svm`](select_feature_set_trainf_svm.md) — Selects an optimal combination of features to classify OCR data.

- [`select_feature_set_trainf_svm_protected`](select_feature_set_trainf_svm_protected.md) — Select an optimal combination of features to classify OCR data
  from a (protected) training file.

- [`serialize_ocr_class_svm`](serialize_ocr_class_svm.md) — Serialize a SVM-based OCR classifier

- [`trainf_ocr_class_svm`](trainf_ocr_class_svm.md) — Train an OCR classifier.

- [`trainf_ocr_class_svm_protected`](trainf_ocr_class_svm_protected.md) — Train an OCR classifier with data from a (protected) training file.

- [`write_ocr_class_svm`](write_ocr_class_svm.md) — Write an OCR classifier to a file.
