## Classification

#### List of Operators

- [`add_samples_image_class_gmm`](add_samples_image_class_gmm.md) — Add training samples from an image to the training data of a
  Gaussian Mixture Model.

- [`add_samples_image_class_knn`](add_samples_image_class_knn.md) — Add training samples from an image to the training data of a
  k-Nearest-Neighbor classifier.

- [`add_samples_image_class_mlp`](add_samples_image_class_mlp.md) — Add training samples from an image to the training data of a
  multilayer perceptron.

- [`add_samples_image_class_svm`](add_samples_image_class_svm.md) — Add training samples from an image to the training data of a support
  vector machine.

- [`class_2dim_sup`](class_2dim_sup.md) — Segment an image using two-dimensional pixel classification.

- [`class_2dim_unsup`](class_2dim_unsup.md) — Segment two images by clustering.

- [`class_ndim_norm`](class_ndim_norm.md) — Classify pixels using hyper-spheres or hyper-cubes.

- [`classify_image_class_gmm`](classify_image_class_gmm.md) — Classify an image with a Gaussian Mixture Model.

- [`classify_image_class_knn`](classify_image_class_knn.md) — Classify an image with a k-Nearest-Neighbor classifier.

- [`classify_image_class_lut`](classify_image_class_lut.md) — Classify a byte image using a look-up table.

- [`classify_image_class_mlp`](classify_image_class_mlp.md) — Classify an image with a multilayer perceptron.

- [`classify_image_class_svm`](classify_image_class_svm.md) — Classify an image with a support vector machine.

- [`learn_ndim_norm`](learn_ndim_norm.md) — Construct classes for [`class_ndim_norm`](class_ndim_norm.md).
