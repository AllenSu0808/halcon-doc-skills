## Features

#### List of Operators

- [`determinant_matrix`](determinant_matrix.md) — Compute the determinant of a matrix.

- [`get_size_matrix`](get_size_matrix.md) — Get the size of a matrix.

- [`max_matrix`](max_matrix.md) — Returns the elementwise maximum of a matrix.

- [`mean_matrix`](mean_matrix.md) — Returns the elementwise mean of a matrix.

- [`min_matrix`](min_matrix.md) — Returns the elementwise minimum of a matrix.

- [`norm_matrix`](norm_matrix.md) — Norm of a matrix.

- [`sum_matrix`](sum_matrix.md) — Returns the elementwise sum of a matrix.
