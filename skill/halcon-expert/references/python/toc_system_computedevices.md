- [`release_all_compute_devices`](release_all_compute_devices.md) — Close all compute devices.

- [`release_compute_device`](release_compute_device.md) — Close a compute_device.

- [`set_compute_device_param`](set_compute_device_param.md) — Set parameters of an compute device.
