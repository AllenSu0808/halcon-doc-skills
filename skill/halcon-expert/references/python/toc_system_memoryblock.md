## Memory Block

#### List of Operators

- [`compare_memory_block`](compare_memory_block.md) — Compare contents of memory blocks regarding equality.

- [`create_memory_block_extern`](create_memory_block_extern.md) — Create a memory block from an external pointer.

- [`create_memory_block_extern_copy`](create_memory_block_extern_copy.md) — Create a memory block from an external pointer by copying.

- [`get_memory_block_ptr`](get_memory_block_ptr.md) — Return the data pointer and size of a memory block.

- [`read_memory_block`](read_memory_block.md) — Read a memory block from a file.

- [`write_memory_block`](write_memory_block.md) — Write a memory block to a file.
