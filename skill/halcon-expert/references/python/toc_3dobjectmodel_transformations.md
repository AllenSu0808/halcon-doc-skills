## Transformations

#### List of Operators

- [`affine_trans_object_model_3d`](affine_trans_object_model_3d.md) — Apply an arbitrary affine 3D transformation to 3D object models.

- [`connection_object_model_3d`](connection_object_model_3d.md) — Determine the connected components of the
  3D object model.

- [`convex_hull_object_model_3d`](convex_hull_object_model_3d.md) — Calculate the convex hull of a 3D object model.

- [`edges_object_model_3d`](edges_object_model_3d.md) — Find edges in a 3D object model.

- [`fuse_object_model_3d`](fuse_object_model_3d.md) — Fuse 3D object models into a surface.

- [`intersect_plane_object_model_3d`](intersect_plane_object_model_3d.md) — Intersect a 3D object model with a plane.

- [`object_model_3d_to_xyz`](object_model_3d_to_xyz.md) — Transform 3D points from a 3D object model to images.

- [`prepare_object_model_3d`](prepare_object_model_3d.md) — Prepare a 3D object model for a certain operation.

- [`project_object_model_3d`](project_object_model_3d.md) — Project a 3D object model into image coordinates.

- [`projective_trans_object_model_3d`](projective_trans_object_model_3d.md) — Apply an arbitrary projective 3D transformation to 3D object models.

- [`register_object_model_3d_global`](register_object_model_3d_global.md) — Improve the relative transformations between 3D object models based on
  their overlaps.

- [`register_object_model_3d_pair`](register_object_model_3d_pair.md) — Search for a transformation between two 3D object models.

- [`render_object_model_3d`](render_object_model_3d.md) — Render 3D object models to get an image.

- [`rigid_trans_object_model_3d`](rigid_trans_object_model_3d.md) — Apply a rigid 3D transformation to 3D object models.

- [`sample_object_model_3d`](sample_object_model_3d.md) — Sample a 3D object model.

- [`simplify_object_model_3d`](simplify_object_model_3d.md) — Simplify a triangulated 3D object model.

- [`smooth_object_model_3d`](smooth_object_model_3d.md) — Smooth the 3D points of a 3D object model.

- [`surface_normals_object_model_3d`](surface_normals_object_model_3d.md) — Calculate the 3D surface normals of a 3D object model.

- [`triangulate_object_model_3d`](triangulate_object_model_3d.md) — Create a surface triangulation for a 3D object model.

- [`xyz_to_object_model_3d`](xyz_to_object_model_3d.md) — Transform 3D points from images to a 3D object model.
