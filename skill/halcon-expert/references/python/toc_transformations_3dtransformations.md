## 3D Transformations

#### List of Operators

- [`affine_trans_point_3d`](affine_trans_point_3d.md) — Apply an arbitrary affine 3D transformation to points.

- [`deserialize_hom_mat3d`](deserialize_hom_mat3d.md) — Deserialize a serialized homogeneous 3D transformation matrix.

- [`hom_mat3d_compose`](hom_mat3d_compose.md) — Multiply two homogeneous 3D transformation matrices.

- [`hom_mat3d_determinant`](hom_mat3d_determinant.md) — Compute the determinant of a homogeneous 3D transformation matrix.

- [`hom_mat3d_identity`](hom_mat3d_identity.md) — Generate the homogeneous transformation matrix of the identical 3D
  transformation.

- [`hom_mat3d_invert`](hom_mat3d_invert.md) — Invert a homogeneous 3D transformation matrix.

- [`hom_mat3d_rotate`](hom_mat3d_rotate.md) — Add a rotation to a homogeneous 3D transformation matrix.

- [`hom_mat3d_rotate_local`](hom_mat3d_rotate_local.md) — Add a rotation to a homogeneous 3D transformation matrix.

- [`hom_mat3d_scale`](hom_mat3d_scale.md) — Add a scaling to a homogeneous 3D transformation matrix.

- [`hom_mat3d_scale_local`](hom_mat3d_scale_local.md) — Add a scaling to a homogeneous 3D transformation matrix.

- [`hom_mat3d_to_pose`](hom_mat3d_to_pose.md) — Convert a homogeneous transformation matrix into a 3D pose.

- [`hom_mat3d_translate`](hom_mat3d_translate.md) — Add a translation to a homogeneous 3D transformation matrix.

- [`hom_mat3d_translate_local`](hom_mat3d_translate_local.md) — Add a translation to a homogeneous 3D transformation matrix.

- [`hom_mat3d_transpose`](hom_mat3d_transpose.md) — Transpose a homogeneous 3D transformation matrix.

- [`point_pluecker_line_to_hom_mat3d`](point_pluecker_line_to_hom_mat3d.md) — Approximate a 3D affine transformation from 3D point-to-line
  correspondences.

- [`pose_to_hom_mat3d`](pose_to_hom_mat3d.md) — Convert a 3D pose into a homogeneous transformation matrix.

- [`projective_trans_hom_point_3d`](projective_trans_hom_point_3d.md) — Project a homogeneous 3D point using a projective transformation
  matrix.

- [`projective_trans_point_3d`](projective_trans_point_3d.md) — Project a 3D point using a projective transformation matrix.

- [`serialize_hom_mat3d`](serialize_hom_mat3d.md) — Serialize a homogeneous 3D transformation matrix.

- [`vector_to_hom_mat3d`](vector_to_hom_mat3d.md) — Approximate a 3D transformation from point correspondences.
