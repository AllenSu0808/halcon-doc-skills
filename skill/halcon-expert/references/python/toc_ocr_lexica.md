## Lexica

#### List of Operators

- [`clear_lexicon`](clear_lexicon.md) — Clear a lexicon.

- [`create_lexicon`](create_lexicon.md) — Create a lexicon from a tuple of words.

- [`import_lexicon`](import_lexicon.md) — Create a lexicon from a text file.

- [`inspect_lexicon`](inspect_lexicon.md) — Query all words from a lexicon.

- [`lookup_lexicon`](lookup_lexicon.md) — Check if a word is contained in a lexicon.

- [`suggest_lexicon`](suggest_lexicon.md) — Find a similar word in a lexicon.
