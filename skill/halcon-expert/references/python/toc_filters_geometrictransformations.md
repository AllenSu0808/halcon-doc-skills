## Geometric Transformations

#### List of Operators

- [`affine_trans_image`](affine_trans_image.md) — Apply an arbitrary affine 2D transformation to images.

- [`affine_trans_image_size`](affine_trans_image_size.md) — Apply an arbitrary affine 2D transformation to an image and specify
  the output image size.

- [`convert_map_type`](convert_map_type.md) — Convert image maps into other map types.

- [`map_image`](map_image.md) — Apply a general transformation to an image.

- [`mirror_image`](mirror_image.md) — Mirror an image.

- [`polar_trans_image_ext`](polar_trans_image_ext.md) — Transform an annular arc in an image to polar coordinates.

- [`polar_trans_image_inv`](polar_trans_image_inv.md) — Transform an image in polar coordinates back to Cartesian coordinates

- [`projective_trans_image`](projective_trans_image.md) — Apply a projective transformation to an image.

- [`projective_trans_image_size`](projective_trans_image_size.md) — Apply a projective transformation to an image and specify the output
  image size.

- [`rotate_image`](rotate_image.md) — Rotate an image about its center.

- [`zoom_image_factor`](zoom_image_factor.md) — Zoom an image by a given factor.

- [`zoom_image_size`](zoom_image_size.md) — Zoom an image to a given size.
