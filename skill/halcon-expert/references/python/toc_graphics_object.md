## Object

#### List of Operators

- [`attach_background_to_window`](attach_background_to_window.md) — Attach a background image to a HALCON window.

- [`attach_drawing_object_to_window`](attach_drawing_object_to_window.md) — Attach an existing drawing object to a HALCON window.

- [`clear_drawing_object`](clear_drawing_object.md) — Delete drawing object.

- [`create_drawing_object_circle`](create_drawing_object_circle.md) — Create a circle which can be modified interactively.

- [`create_drawing_object_circle_sector`](create_drawing_object_circle_sector.md) — Create a circle sector which can be modified interactively.

- [`create_drawing_object_ellipse`](create_drawing_object_ellipse.md) — Create an ellipse which can be modified interactively.

- [`create_drawing_object_ellipse_sector`](create_drawing_object_ellipse_sector.md) — Create an elliptic sector which can be modified interactively.

- [`create_drawing_object_line`](create_drawing_object_line.md) — Create a line which can be modified interactively.

- [`create_drawing_object_rectangle1`](create_drawing_object_rectangle1.md) — Create a rectangle parallel to the coordinate axis which can be
  modified interactively.

- [`create_drawing_object_rectangle2`](create_drawing_object_rectangle2.md) — Create a rectangle of any orientation which can be modified interactively.

- [`create_drawing_object_text`](create_drawing_object_text.md) — Create a text object which can be moved interactively.

- [`create_drawing_object_xld`](create_drawing_object_xld.md) — Create a XLD contour which can be modified interactively.

- [`detach_background_from_window`](detach_background_from_window.md) — Detach the background image from a HALCON window.

- [`detach_drawing_object_from_window`](detach_drawing_object_from_window.md) — Detach an existing drawing object from a HALCON window.

- [`get_drawing_object_iconic`](get_drawing_object_iconic.md) — Return the iconic object of a drawing object.

- [`get_drawing_object_params`](get_drawing_object_params.md) — Get the parameters of a drawing object.

- [`get_window_background_image`](get_window_background_image.md) — Gets a copy of the background image of the HALCON window.

- [`set_content_update_callback`](set_content_update_callback.md) — Sets the callback for content updates in buffer window.

- [`set_drawing_object_callback`](set_drawing_object_callback.md) — Add a callback function to a drawing object.

- [`set_drawing_object_params`](set_drawing_object_params.md) — Set the parameters of a drawing object.

- [`set_drawing_object_xld`](set_drawing_object_xld.md) — Set the contour of an interactive draw XLD.
