## Access

#### List of Operators

- [`get_contour_xld`](get_contour_xld.md) — Return the coordinates of an XLD contour.

- [`get_lines_xld`](get_lines_xld.md) — Return an XLD polygon's data (as lines).

- [`get_parallels_xld`](get_parallels_xld.md) — Return an XLD parallel's data (as lines).

- [`get_polygon_xld`](get_polygon_xld.md) — Return an XLD polygon's data.
