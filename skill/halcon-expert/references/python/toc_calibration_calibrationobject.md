## Calibration Object

#### List of Operators

- [`caltab_points`](caltab_points.md) — Read the mark center points from the calibration plate description file.

- [`create_caltab`](create_caltab.md) — Generate a calibration plate description file and a corresponding
  PostScript file for a calibration plate with hexagonally arranged marks.

- [`disp_caltab`](disp_caltab.md) — Project and visualize the 3D model of the calibration plate in the image.

- [`find_calib_object`](find_calib_object.md) — Find the HALCON calibration plate and set the extracted points and
  contours in a calibration data model.

- [`find_caltab`](find_caltab.md) — Segment the region of a standard calibration plate with rectangularly
  arranged marks in the image.

- [`find_marks_and_pose`](find_marks_and_pose.md) — Extract rectangularly arranged 2D calibration marks from the image and
  calculate initial values for the external camera parameters.

- [`gen_caltab`](gen_caltab.md) — Generate a calibration plate description file and a corresponding
  PostScript file for a calibration plate with rectangularly arranged marks.

- [`sim_caltab`](sim_caltab.md) — Simulate an image with calibration plate.
