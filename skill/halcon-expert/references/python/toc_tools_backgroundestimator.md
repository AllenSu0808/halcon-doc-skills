## Background Estimator

#### List of Operators

- [`close_bg_esti`](close_bg_esti.md) — Delete the background estimation data set.

- [`create_bg_esti`](create_bg_esti.md) — Generate and initialize a data set for the background estimation.

- [`get_bg_esti_params`](get_bg_esti_params.md) — Return the parameters of the data set.

- [`give_bg_esti`](give_bg_esti.md) — Return the estimated background image.

- [`run_bg_esti`](run_bg_esti.md) — Estimate the background and return the foreground region.

- [`set_bg_esti_params`](set_bg_esti_params.md) — Change the parameters of the data set.

- [`update_bg_esti`](update_bg_esti.md) — Change the estimated background image.
