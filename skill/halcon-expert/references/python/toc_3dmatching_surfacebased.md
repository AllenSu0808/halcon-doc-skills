## Surface-Based

#### List of Operators

- [`clear_surface_matching_result`](clear_surface_matching_result.md) — Free the memory of a surface matching result.

- [`clear_surface_model`](clear_surface_model.md) — Free the memory of a surface model.

- [`create_surface_model`](create_surface_model.md) — Create the data structure needed to perform surface-based matching.

- [`deserialize_surface_model`](deserialize_surface_model.md) — Deserialize a surface model.

- [`find_surface_model`](find_surface_model.md) — Find the best matches of a surface model in a 3D scene.

- [`find_surface_model_image`](find_surface_model_image.md) — Find the best matches of a surface model in a 3D scene and images.

- [`get_surface_matching_result`](get_surface_matching_result.md) — Get details of a result from surface based matching.

- [`get_surface_model_param`](get_surface_model_param.md) — Return the parameters and properties of a surface model.

- [`read_surface_model`](read_surface_model.md) — Read a surface model from a file.

- [`refine_surface_model_pose`](refine_surface_model_pose.md) — Refine the pose of a surface model in a 3D scene.

- [`refine_surface_model_pose_image`](refine_surface_model_pose_image.md) — Refine the pose of a surface model in a 3D scene and in images.

- [`serialize_surface_model`](serialize_surface_model.md) — Serialize a surface_model.

- [`set_surface_model_param`](set_surface_model_param.md) — Set parameters and properties of a surface model.

- [`write_surface_model`](write_surface_model.md) — Write a surface model to a file.
