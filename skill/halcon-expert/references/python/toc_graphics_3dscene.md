## 3D Scene

#### List of Operators

- [`add_scene_3d_camera`](add_scene_3d_camera.md) — Add a camera to a 3D scene.

- [`add_scene_3d_instance`](add_scene_3d_instance.md) — Add an instance of a 3D object model to a 3D scene.

- [`add_scene_3d_label`](add_scene_3d_label.md) — Add a text label to a 3D scene.

- [`add_scene_3d_light`](add_scene_3d_light.md) — Add a light source to a 3D scene.

- [`clear_scene_3d`](clear_scene_3d.md) — Delete a 3D scene and free all allocated memory.

- [`create_scene_3d`](create_scene_3d.md) — Create the data structure that is needed to visualize collections of
  3D objects.

- [`display_scene_3d`](display_scene_3d.md) — Display a 3D scene.

- [`get_display_scene_3d_info`](get_display_scene_3d_info.md) — Get the depth or the index of instances in a displayed 3D scene.

- [`remove_scene_3d_camera`](remove_scene_3d_camera.md) — Remove a camera from a 3D scene.

- [`remove_scene_3d_instance`](remove_scene_3d_instance.md) — Remove an object instance from a 3D scene.

- [`remove_scene_3d_label`](remove_scene_3d_label.md) — Remove a text label from a 3D scene.

- [`remove_scene_3d_light`](remove_scene_3d_light.md) — Remove a light from a 3D scene.

- [`render_scene_3d`](render_scene_3d.md) — Render an image of a 3D scene.

- [`set_scene_3d_camera_pose`](set_scene_3d_camera_pose.md) — Set the pose of a camera in a 3D scene.

- [`set_scene_3d_instance_param`](set_scene_3d_instance_param.md) — Set parameters of an instance in a 3D scene.

- [`set_scene_3d_instance_pose`](set_scene_3d_instance_pose.md) — Set the pose of an instance in a 3D scene.

- [`set_scene_3d_label_param`](set_scene_3d_label_param.md) — Set parameters of a text label in a 3D scene.

- [`set_scene_3d_light_param`](set_scene_3d_light_param.md) — Set parameters of a light in a 3D scene.

- [`set_scene_3d_param`](set_scene_3d_param.md) — Set parameters of a 3D scene.

- [`set_scene_3d_to_world_pose`](set_scene_3d_to_world_pose.md) — Set the pose of a 3D scene.
