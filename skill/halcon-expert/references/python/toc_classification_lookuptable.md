## Look-Up Table

#### List of Operators

- [`clear_class_lut`](clear_class_lut.md) — Clear a look-up table classifier.

- [`create_class_lut_gmm`](create_class_lut_gmm.md) — Create a look-up table using a Gaussian mixture model to classify byte
  images.

- [`create_class_lut_knn`](create_class_lut_knn.md) — Create a look-up table using a k-nearest neighbors
  classifier (k-NN) to classify byte
  images.

- [`create_class_lut_mlp`](create_class_lut_mlp.md) — Create a look-up table using a multi-layer perceptron to classify byte
  images.

- [`create_class_lut_svm`](create_class_lut_svm.md) — Create a look-up table using a Support-Vector-Machine to classify byte
  images.
