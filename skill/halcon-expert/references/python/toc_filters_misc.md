## Misc

#### List of Operators

- [`convol_channels`](convol_channels.md) — Perform a convolution along the channel dimension.

- [`convol_image`](convol_image.md) — Calculate the correlation between an image and an arbitrary filter mask

- [`deviation_n`](deviation_n.md) — Calculate standard deviation over several channels.

- [`expand_domain_gray`](expand_domain_gray.md) — Expand the domain of an image and set the gray values in the
  expanded domain.

- [`gen_savitzky_golay_filter`](gen_savitzky_golay_filter.md) — Compute the filter coefficients of a Savitzky-Golay filter.

- [`gray_inside`](gray_inside.md) — Calculate the lowest possible gray value on an arbitrary path to the
  image border for each point in the image.

- [`gray_skeleton`](gray_skeleton.md) — Thinning of gray value images.

- [`lut_trans`](lut_trans.md) — Transform an image with a gray-value look-up-table

- [`symmetry`](symmetry.md) — Symmetry of gray values along a row.

- [`topographic_sketch`](topographic_sketch.md) — Compute the topographic primal sketch of an image.
