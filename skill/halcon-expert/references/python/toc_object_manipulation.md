## Manipulation

#### List of Operators

- [`clear_obj`](clear_obj.md) — Delete an iconic object from the HALCON database.

- [`concat_obj`](concat_obj.md) — Concatenate two iconic object tuples.

- [`copy_obj`](copy_obj.md) — Copy an iconic object in the HALCON database.

- [`gen_empty_obj`](gen_empty_obj.md) — Create an empty object tuple.

- [`insert_obj`](insert_obj.md) — Insert objects into an iconic object tuple.

- [`integer_to_obj`](integer_to_obj.md) — Convert an “integer number” into an iconic object.

- [`obj_diff`](obj_diff.md) — Calculate the difference of two object tuples.

- [`obj_to_integer`](obj_to_integer.md) — Convert an iconic object into an “integer number.”

- [`remove_obj`](remove_obj.md) — Remove objects from an iconic object tuple.

- [`replace_obj`](replace_obj.md) — Replaces one or more elements of an iconic object tuple.

- [`select_obj`](select_obj.md) — Select objects from an object tuple.
