## Features

#### List of Operators

- [`get_handle_object`](get_handle_object.md) — Retrieve an object associated with a key from a handle.

- [`get_handle_param`](get_handle_param.md) — Return information about a handle.

- [`get_handle_tuple`](get_handle_tuple.md) — Retrieve a tuple associated with a key from a handle.

- [`tuple_deviation`](tuple_deviation.md) — Return the standard deviation of the elements of a tuple.

- [`tuple_histo_range`](tuple_histo_range.md) — Calculate the value distribution of a tuple within a certain value range.

- [`tuple_length`](tuple_length.md) — Return the number of elements of a tuple.

- [`tuple_max`](tuple_max.md) — Return the maximal element of a tuple.

- [`tuple_mean`](tuple_mean.md) — Return the mean value of a tuple of numbers.

- [`tuple_median`](tuple_median.md) — Return the median of the elements of a tuple.

- [`tuple_min`](tuple_min.md) — Return the minimal element of a tuple.

- [`tuple_sum`](tuple_sum.md) — Return the sum of all elements of a tuple.
