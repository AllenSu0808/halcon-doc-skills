## Edges

#### List of Operators

- [`CloseEdges`](close_edges.md) — Close edge gaps using the edge amplitude image.

- [`CloseEdgesLength`](close_edges_length.md) — Close edge gaps using the edge amplitude image.

- [`DerivateGauss`](derivate_gauss.md) — Convolve an image with derivatives of the Gaussian.

- [`DiffOfGauss`](diff_of_gauss.md) — Approximate the LoG operator (Laplace of Gaussian).

- [`EdgesColor`](edges_color.md) — Extract color edges using Canny, Deriche, or Shen filters.

- [`EdgesColorSubPix`](edges_color_sub_pix.md) — Extract subpixel precise color edges using Deriche, Shen, or Canny filters.

- [`EdgesImage`](edges_image.md) — Extract edges using Deriche, Lanser, Shen, or Canny filters.

- [`EdgesSubPix`](edges_sub_pix.md) — Extract sub-pixel precise edges using Deriche, Lanser, Shen, or Canny
  filters.

- [`FreiAmp`](frei_amp.md) — Detect edges (amplitude) using the Frei-Chen operator.

- [`FreiDir`](frei_dir.md) — Detect edges (amplitude and direction) using the Frei-Chen operator.

- [`HighpassImage`](highpass_image.md) — Extract high frequency components from an image.

- [`InfoEdges`](info_edges.md) — Return the filter coefficients of a filter in [`EdgesImage`](edges_image.md).

- [`KirschAmp`](kirsch_amp.md) — Detect edges (amplitude) using the Kirsch operator.

- [`KirschDir`](kirsch_dir.md) — Detect edges (amplitude and direction) using the Kirsch operator.

- [`Laplace`](laplace.md) — Calculate the Laplace operator by using finite differences.

- [`LaplaceOfGauss`](laplace_of_gauss.md) — LoG-Operator (Laplace of Gaussian).

- [`PrewittAmp`](prewitt_amp.md) — Detect edges (amplitude) using the Prewitt operator.

- [`PrewittDir`](prewitt_dir.md) — Detect edges (amplitude and direction) using the Prewitt operator.

- [`Roberts`](roberts.md) — Detect edges using the Roberts filter.

- [`RobinsonAmp`](robinson_amp.md) — Detect edges (amplitude) using the Robinson operator.

- [`RobinsonDir`](robinson_dir.md) — Detect edges (amplitude and direction) using the Robinson operator.

- [`SobelAmp`](sobel_amp.md) — Detect edges (amplitude) using the Sobel operator.

- [`SobelDir`](sobel_dir.md) — Detect edges (amplitude and direction) using the Sobel operator.
