## Shape-Based

#### List of Operators

- [`ClearShapeModel3d`](clear_shape_model_3d.md) — Free the memory of a 3D shape model.

- [`CreateCamPoseLookAtPoint`](create_cam_pose_look_at_point.md) — Create a 3D camera pose from camera center and viewing direction.

- [`CreateShapeModel3d`](create_shape_model_3d.md) — Prepare a 3D object model for matching.

- [`DeserializeShapeModel3d`](deserialize_shape_model_3d.md) — Deserialize a serialized 3D shape model.

- [`FindShapeModel3d`](find_shape_model_3d.md) — Find the best matches of a 3D shape model in an image.

- [`GetShapeModel3dContours`](get_shape_model_3d_contours.md) — Return the contour representation of a 3D shape model view.

- [`GetShapeModel3dParams`](get_shape_model_3d_params.md) — Return the parameters of a 3D shape model.

- [`ProjectShapeModel3d`](project_shape_model_3d.md) — Project the edges of a 3D shape model into image coordinates.

- [`ReadShapeModel3d`](read_shape_model_3d.md) — Read a 3D shape model from a file.

- [`SerializeShapeModel3d`](serialize_shape_model_3d.md) — Serialize a 3D shape model.

- [`TransPoseShapeModel3d`](trans_pose_shape_model_3d.md) — Transform a pose that refers to the coordinate system of a 3D object
  model to a pose that refers to the reference coordinate system of a
  3D shape model and vice versa.

- [`WriteShapeModel3d`](write_shape_model_3d.md) — Write a 3D shape model to a file.
