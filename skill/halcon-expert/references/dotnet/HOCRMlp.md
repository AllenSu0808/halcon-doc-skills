# HOCRMlp (Class)

## Name

`HOCRMlp` — Represents an instance of a MLP OCR classifier.

## Constructors

|  |  |  |
| --- | --- | --- |
| `ReadOcrClassMlp` |  | Read an OCR classifier from a file. |
| `CreateOcrClassMlp` |  | Create an OCR classifier using a multilayer perceptron. |
