## Segmentation

#### List of Operators

- [`FitPrimitivesObjectModel3d`](fit_primitives_object_model_3d.md) — Fit 3D primitives into a set of 3D points.

- [`ReduceObjectModel3dByView`](reduce_object_model_3d_by_view.md) — Remove points from a 3D object model by projecting it to a virtual view
  and removing all points outside of a given region.

- [`SegmentObjectModel3d`](segment_object_model_3d.md) — Segment a set of 3D points into sub-sets with similar characteristics.

- [`SelectPointsObjectModel3d`](select_points_object_model_3d.md) — Apply a threshold to an attribute of 3D object models.
