## 3D Scene

#### List of Operators

- [`AddScene3dCamera`](add_scene_3d_camera.md) — Add a camera to a 3D scene.

- [`AddScene3dInstance`](add_scene_3d_instance.md) — Add an instance of a 3D object model to a 3D scene.

- [`AddScene3dLabel`](add_scene_3d_label.md) — Add a text label to a 3D scene.

- [`AddScene3dLight`](add_scene_3d_light.md) — Add a light source to a 3D scene.

- [`ClearScene3d`](clear_scene_3d.md) — Delete a 3D scene and free all allocated memory.

- [`CreateScene3d`](create_scene_3d.md) — Create the data structure that is needed to visualize collections of
  3D objects.

- [`DisplayScene3d`](display_scene_3d.md) — Display a 3D scene.

- [`GetDisplayScene3dInfo`](get_display_scene_3d_info.md) — Get the depth or the index of instances in a displayed 3D scene.

- [`RemoveScene3dCamera`](remove_scene_3d_camera.md) — Remove a camera from a 3D scene.

- [`RemoveScene3dInstance`](remove_scene_3d_instance.md) — Remove an object instance from a 3D scene.

- [`RemoveScene3dLabel`](remove_scene_3d_label.md) — Remove a text label from a 3D scene.

- [`RemoveScene3dLight`](remove_scene_3d_light.md) — Remove a light from a 3D scene.

- [`RenderScene3d`](render_scene_3d.md) — Render an image of a 3D scene.

- [`SetScene3dCameraPose`](set_scene_3d_camera_pose.md) — Set the pose of a camera in a 3D scene.

- [`SetScene3dInstanceParam`](set_scene_3d_instance_param.md) — Set parameters of an instance in a 3D scene.

- [`SetScene3dInstancePose`](set_scene_3d_instance_pose.md) — Set the pose of an instance in a 3D scene.

- [`SetScene3dLabelParam`](set_scene_3d_label_param.md) — Set parameters of a text label in a 3D scene.

- [`SetScene3dLightParam`](set_scene_3d_light_param.md) — Set parameters of a light in a 3D scene.

- [`SetScene3dParam`](set_scene_3d_param.md) — Set parameters of a 3D scene.

- [`SetScene3dToWorldPose`](set_scene_3d_to_world_pose.md) — Set the pose of a 3D scene.
