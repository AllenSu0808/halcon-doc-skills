## Access

#### List of Operators

- [`GetGrayval`](get_grayval.md) — Access the gray values of an image object.

- [`GetGrayvalContourXld`](get_grayval_contour_xld.md) — Return gray values of an image at the positions of an XLD contour.

- [`GetGrayvalInterpolated`](get_grayval_interpolated.md) — Return gray values of an image at the positions given by tuples of
  rows and columns.

- [`GetImagePointer1`](get_image_pointer1.md) — Access the pointer of a channel.

- [`GetImagePointer1Rect`](get_image_pointer1_rect.md) — Access to the image data pointer and the image data inside
  the smallest rectangle of the domain of the input image.

- [`GetImagePointer3`](get_image_pointer3.md) — Access the pointers of a colored image.

- [`GetImageSize`](get_image_size.md) — Return the size of an image.

- [`GetImageTime`](get_image_time.md) — Request time at which the image was created.

- [`GetImageType`](get_image_type.md) — Return the type of an image.
