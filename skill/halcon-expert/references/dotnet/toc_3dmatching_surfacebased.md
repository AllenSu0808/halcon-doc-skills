## Surface-Based

#### List of Operators

- [`ClearSurfaceMatchingResult`](clear_surface_matching_result.md) — Free the memory of a surface matching result.

- [`ClearSurfaceModel`](clear_surface_model.md) — Free the memory of a surface model.

- [`CreateSurfaceModel`](create_surface_model.md) — Create the data structure needed to perform surface-based matching.

- [`DeserializeSurfaceModel`](deserialize_surface_model.md) — Deserialize a surface model.

- [`FindSurfaceModel`](find_surface_model.md) — Find the best matches of a surface model in a 3D scene.

- [`FindSurfaceModelImage`](find_surface_model_image.md) — Find the best matches of a surface model in a 3D scene and images.

- [`GetSurfaceMatchingResult`](get_surface_matching_result.md) — Get details of a result from surface based matching.

- [`GetSurfaceModelParam`](get_surface_model_param.md) — Return the parameters and properties of a surface model.

- [`ReadSurfaceModel`](read_surface_model.md) — Read a surface model from a file.

- [`RefineSurfaceModelPose`](refine_surface_model_pose.md) — Refine the pose of a surface model in a 3D scene.

- [`RefineSurfaceModelPoseImage`](refine_surface_model_pose_image.md) — Refine the pose of a surface model in a 3D scene and in images.

- [`SerializeSurfaceModel`](serialize_surface_model.md) — Serialize a surface_model.

- [`SetSurfaceModelParam`](set_surface_model_param.md) — Set parameters and properties of a surface model.

- [`WriteSurfaceModel`](write_surface_model.md) — Write a surface model to a file.
