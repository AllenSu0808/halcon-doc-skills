# HDlTransform (Class)

## Name

`HDlTransform` — Represents an instance of a Deep Learning transformation.

## Constructors

|  |  |  |
| --- | --- | --- |
| `CreateDlTransformBlur` |  | Create a blur transform. |
| `CreateDlTransformRandomGeometric` |  | Create a random geometric transform. |
| `CreateDlTransformRandomCrop` |  | Create a random crop transform. |
| `CreateDlTransformRandomHsv` |  | Create a random HSV transform. |
| `CreateDlTransformNormalize` |  | Create a normalize transform. |
| `CreateDlTransformFlip` |  | Create a flip transform. |
| `CreateDlTransformResize` |  | Create a resize transform using absolute dimensions. |
