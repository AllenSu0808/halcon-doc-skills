## Classification

#### List of Operators

- [`AddSamplesImageClassGmm`](add_samples_image_class_gmm.md) — Add training samples from an image to the training data of a
  Gaussian Mixture Model.

- [`AddSamplesImageClassKnn`](add_samples_image_class_knn.md) — Add training samples from an image to the training data of a
  k-Nearest-Neighbor classifier.

- [`AddSamplesImageClassMlp`](add_samples_image_class_mlp.md) — Add training samples from an image to the training data of a
  multilayer perceptron.

- [`AddSamplesImageClassSvm`](add_samples_image_class_svm.md) — Add training samples from an image to the training data of a support
  vector machine.

- [`Class2dimSup`](class_2dim_sup.md) — Segment an image using two-dimensional pixel classification.

- [`Class2dimUnsup`](class_2dim_unsup.md) — Segment two images by clustering.

- [`ClassNdimNorm`](class_ndim_norm.md) — Classify pixels using hyper-spheres or hyper-cubes.

- [`ClassifyImageClassGmm`](classify_image_class_gmm.md) — Classify an image with a Gaussian Mixture Model.

- [`ClassifyImageClassKnn`](classify_image_class_knn.md) — Classify an image with a k-Nearest-Neighbor classifier.

- [`ClassifyImageClassLut`](classify_image_class_lut.md) — Classify a byte image using a look-up table.

- [`ClassifyImageClassMlp`](classify_image_class_mlp.md) — Classify an image with a multilayer perceptron.

- [`ClassifyImageClassSvm`](classify_image_class_svm.md) — Classify an image with a support vector machine.

- [`LearnNdimNorm`](learn_ndim_norm.md) — Construct classes for [`ClassNdimNorm`](class_ndim_norm.md).
