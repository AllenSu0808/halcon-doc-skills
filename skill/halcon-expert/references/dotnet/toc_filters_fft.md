## FFT

#### List of Operators

- [`ConvolFft`](convol_fft.md) — Multiply an image with a filter image in the frequency domain.

- [`ConvolGabor`](convol_gabor.md) — Convolve an image with a Gabor filter in the frequency domain.

- [`CorrelationFft`](correlation_fft.md) — Multiply one image with the complex conjugate of another image in the
  frequency domain.

- [`DeserializeFftOptimizationData`](deserialize_fft_optimization_data.md) — Deserialize FFT speed optimization data.

- [`EnergyGabor`](energy_gabor.md) — Calculate the energy of a two-channel image.

- [`FftGeneric`](fft_generic.md) — Compute the fast Fourier transform of an image.

- [`FftImage`](fft_image.md) — Compute the fast Fourier transform of an image.

- [`FftImageInv`](fft_image_inv.md) — Compute the inverse fast Fourier transform of an image.

- [`GenBandfilter`](gen_bandfilter.md) — Generate an ideal band filter.

- [`GenBandpass`](gen_bandpass.md) — Generate an ideal bandpass filter.

- [`GenDerivativeFilter`](gen_derivative_filter.md) — Generate a derivative filter in the frequency domain.

- [`GenFilterMask`](gen_filter_mask.md) — Store a filter mask in the spatial domain as a real-image.

- [`GenGabor`](gen_gabor.md) — Generate a Gabor filter.

- [`GenGaussFilter`](gen_gauss_filter.md) — Generate a Gaussian filter in the frequency domain.

- [`GenHighpass`](gen_highpass.md) — Generate an ideal highpass filter.

- [`GenLowpass`](gen_lowpass.md) — Generate an ideal lowpass filter.

- [`GenMeanFilter`](gen_mean_filter.md) — Generate a mean filter in the frequency domain.

- [`GenSinBandpass`](gen_sin_bandpass.md) — Generate a bandpass filter with sinusoidal shape.

- [`GenStdBandpass`](gen_std_bandpass.md) — Generate a bandpass filter with Gaussian or sinusoidal shape.

- [`OptimizeFftSpeed`](optimize_fft_speed.md) — Optimize the runtime of the FFT.

- [`OptimizeRftSpeed`](optimize_rft_speed.md) — Optimize the runtime of the real-valued FFT.

- [`PhaseCorrelationFft`](phase_correlation_fft.md) — Compute the phase correlation of two images in the frequency domain.

- [`PhaseDeg`](phase_deg.md) — Return the phase of a complex image in degrees.

- [`PhaseRad`](phase_rad.md) — Return the phase of a complex image in radians.

- [`PowerByte`](power_byte.md) — Return the power spectrum of a complex image.

- [`PowerLn`](power_ln.md) — Return the power spectrum of a complex image.

- [`PowerReal`](power_real.md) — Return the power spectrum of a complex image.

- [`ReadFftOptimizationData`](read_fft_optimization_data.md) — Load FFT speed optimization data from a file.

- [`RftGeneric`](rft_generic.md) — Compute the real-valued fast Fourier transform of an image.

- [`SerializeFftOptimizationData`](serialize_fft_optimization_data.md) — Serialize FFT speed optimization data.

- [`WriteFftOptimizationData`](write_fft_optimization_data.md) — Store FFT speed optimization data in a file.
