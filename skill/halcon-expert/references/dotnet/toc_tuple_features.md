## Features

#### List of Operators

- [`GetHandleObject`](get_handle_object.md) — Retrieve an object associated with a key from a handle.

- [`GetHandleParam`](get_handle_param.md) — Return information about a handle.

- [`GetHandleTuple`](get_handle_tuple.md) — Retrieve a tuple associated with a key from a handle.

- [`TupleDeviation`](tuple_deviation.md) — Return the standard deviation of the elements of a tuple.

- [`TupleHistoRange`](tuple_histo_range.md) — Calculate the value distribution of a tuple within a certain value range.

- [`TupleLength`](tuple_length.md) — Return the number of elements of a tuple.

- [`TupleMax`](tuple_max.md) — Return the maximal element of a tuple.

- [`TupleMean`](tuple_mean.md) — Return the mean value of a tuple of numbers.

- [`TupleMedian`](tuple_median.md) — Return the median of the elements of a tuple.

- [`TupleMin`](tuple_min.md) — Return the minimal element of a tuple.

- [`TupleSum`](tuple_sum.md) — Return the sum of all elements of a tuple.
