## Bead Inspection

#### List of Operators

- [`ApplyBeadInspectionModel`](apply_bead_inspection_model.md) — Inspect beads in an image, as defined by the bead inspection
  model.

- [`ClearBeadInspectionModel`](clear_bead_inspection_model.md) — Delete the bead inspection model and free the allocated memory.

- [`CreateBeadInspectionModel`](create_bead_inspection_model.md) — Create a model to inspect beads or adhesive in images.

- [`GetBeadInspectionParam`](get_bead_inspection_param.md) — Get the value of a parameter in a specific bead inspection model.

- [`SetBeadInspectionParam`](set_bead_inspection_param.md) — Set parameters of the bead inspection model.
