## Manipulation

#### List of Operators

- [`ClearObj`](clear_obj.md) — Delete an iconic object from the HALCON database.

- [`ConcatObj`](concat_obj.md) — Concatenate two iconic object tuples.

- [`CopyObj`](copy_obj.md) — Copy an iconic object in the HALCON database.

- [`GenEmptyObj`](gen_empty_obj.md) — Create an empty object tuple.

- [`InsertObj`](insert_obj.md) — Insert objects into an iconic object tuple.

- [`IntegerToObj`](integer_to_obj.md) — Convert an “integer number” into an iconic object.

- [`ObjDiff`](obj_diff.md) — Calculate the difference of two object tuples.

- [`ObjToInteger`](obj_to_integer.md) — Convert an iconic object into an “integer number.”

- [`RemoveObj`](remove_obj.md) — Remove objects from an iconic object tuple.

- [`ReplaceObj`](replace_obj.md) — Replaces one or more elements of an iconic object tuple.

- [`SelectObj`](select_obj.md) — Select objects from an object tuple.
