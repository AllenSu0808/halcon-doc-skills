## Segmentation

#### List of Operators

- [`ClearTextModel`](clear_text_model.md) — Clear a text model.

- [`ClearTextResult`](clear_text_result.md) — Clear a text result.

- [`CreateTextModelReader`](create_text_model_reader.md) — Create a text model.

- [`FindText`](find_text.md) — Find text in an image.

- [`GetTextModelParam`](get_text_model_param.md) — Query parameters of a text model.

- [`GetTextObject`](get_text_object.md) — Query an iconic value of a text segmentation result.

- [`GetTextResult`](get_text_result.md) — Query a control value of a text segmentation result.

- [`SegmentCharacters`](segment_characters.md) — Segments characters in a given region of an image.

- [`SelectCharacters`](select_characters.md) — Selects characters from a given region.

- [`SetTextModelParam`](set_text_model_param.md) — Set parameters of a text model.

- [`TextLineOrientation`](text_line_orientation.md) — Determines the orientation of a text line or paragraph.

- [`TextLineSlant`](text_line_slant.md) — Determines the slant of characters of a text line or paragraph.
