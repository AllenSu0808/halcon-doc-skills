## Format

#### List of Operators

- [`AddImageBorder`](add_image_border.md) — Add a border to an image.

- [`ChangeFormat`](change_format.md) — Change image size.

- [`CropDomain`](crop_domain.md) — Cut out of defined gray values.

- [`CropDomainRel`](crop_domain_rel.md) — Cut out an image area relative to the domain.

- [`CropPart`](crop_part.md) — Cut out one or more rectangular image areas.

- [`CropRectangle1`](crop_rectangle1.md) — Cut out one or more rectangular image areas.

- [`CropRectangle2`](crop_rectangle2.md) — Cut out one or more arbitrarily oriented rectangular image areas.

- [`TileChannels`](tile_channels.md) — Tile multiple images into a large image.

- [`TileImages`](tile_images.md) — Tile multiple image objects into a large image.

- [`TileImagesOffset`](tile_images_offset.md) — Tile multiple image objects into a large image with explicit
  positioning information.
