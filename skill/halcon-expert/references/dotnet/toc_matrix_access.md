## Access

#### List of Operators

- [`GetDiagonalMatrix`](get_diagonal_matrix.md) — Get the diagonal elements of a matrix.

- [`GetFullMatrix`](get_full_matrix.md) — Return all values of a matrix.

- [`GetSubMatrix`](get_sub_matrix.md) — Get a sub-matrix of a matrix.

- [`GetValueMatrix`](get_value_matrix.md) — Return one ore more elements of a matrix.

- [`SetDiagonalMatrix`](set_diagonal_matrix.md) — Set the diagonal elements of a matrix.

- [`SetFullMatrix`](set_full_matrix.md) — Set all values of a matrix.

- [`SetSubMatrix`](set_sub_matrix.md) — Set a sub-matrix of a matrix.

- [`SetValueMatrix`](set_value_matrix.md) — Set one or more elements of a matrix.
