## Text

#### List of Operators

- [`DispText`](disp_text.md) — Display text in a window.

- [`GetFont`](get_font.md) — Get the current font.

- [`GetFontExtents`](get_font_extents.md) — Get the maximum size of all characters of a font.

- [`GetStringExtents`](get_string_extents.md) — Get the spatial size of a string.

- [`GetTposition`](get_tposition.md) — Get cursor position.

- [`NewLine`](new_line.md) — Set the position of the text cursor to the beginning of the next line.

- [`QueryFont`](query_font.md) — Query the available fonts.

- [`ReadChar`](read_char.md) — Read a character from a window.

- [`ReadString`](read_string.md) — Read a string in a text window.

- [`SetFont`](set_font.md) — Set the font used for text output.

- [`SetTposition`](set_tposition.md) — Set the position of the text cursor.

- [`WriteString`](write_string.md) — Print text in a window.
