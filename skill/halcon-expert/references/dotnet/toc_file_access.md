## Access

#### List of Operators

- [`CloseFile`](close_file.md) — Closing a text file.

- [`FnewLine`](fnew_line.md) — Write a line break and clear the output buffer.

- [`FreadBytes`](fread_bytes.md) — Read bytes from a binary file.

- [`FreadChar`](fread_char.md) — Read one character from a text file.

- [`FreadLine`](fread_line.md) — Read a character line from a text file.

- [`FreadString`](fread_string.md) — Read a string from a text file.

- [`FwriteBytes`](fwrite_bytes.md) — Write bytes to a binary file.

- [`FwriteString`](fwrite_string.md) — Write strings and numbers into a text file.

- [`OpenFile`](open_file.md) — Open a file in text or binary format.
