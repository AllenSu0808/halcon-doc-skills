## K-Nearest Neighbors

#### List of Operators

- [`AddClassTrainDataKnn`](add_class_train_data_knn.md) — Add training data to a k-nearest neighbors (k-NN) classifier.

- [`AddSampleClassKnn`](add_sample_class_knn.md) — Add a sample to a k-nearest neighbors (k-NN) classifier.

- [`ClassifyClassKnn`](classify_class_knn.md) — Search for the next neighbors for a given feature vector.

- [`ClearClassKnn`](clear_class_knn.md) — Clear a k-NN classifier.

- [`CreateClassKnn`](create_class_knn.md) — Create a k-nearest neighbors (k-NN) classifier.

- [`DeserializeClassKnn`](deserialize_class_knn.md) — Deserialize a serialized k-NN classifier.

- [`GetClassTrainDataKnn`](get_class_train_data_knn.md) — Get the training data of a k-nearest neighbors (k-NN) classifier.

- [`GetParamsClassKnn`](get_params_class_knn.md) — Get parameters of a k-NN classification.

- [`GetSampleClassKnn`](get_sample_class_knn.md) — Return a training sample from the training data of a k-nearest neighbors
  (k-NN) classifier.

- [`GetSampleNumClassKnn`](get_sample_num_class_knn.md) — Return the number of training samples stored in the training data of
  a k-nearest neighbors (k-NN) classifier.

- [`ReadClassKnn`](read_class_knn.md) — Read the k-NN classifier from a file.

- [`SelectFeatureSetKnn`](select_feature_set_knn.md) — Selects an optimal subset from a set of features to solve a certain
  classification problem.

- [`SerializeClassKnn`](serialize_class_knn.md) — Serialize a k-NN classifier.

- [`SetParamsClassKnn`](set_params_class_knn.md) — Set parameters for k-NN classification.

- [`TrainClassKnn`](train_class_knn.md) — Creates the search trees for a k-NN classifier.

- [`WriteClassKnn`](write_class_knn.md) — Save the k-NN classifier in a file.
