## Creation

#### List of Operators

- [`ClearObjectModel3d`](clear_object_model_3d.md) — Free the memory of a 3D object model.

- [`DeserializeObjectModel3d`](deserialize_object_model_3d.md) — Deserialize a serialized 3D object model.

- [`GenBoxObjectModel3d`](gen_box_object_model_3d.md) — Create a 3D object model that represents a box.

- [`GenCylinderObjectModel3d`](gen_cylinder_object_model_3d.md) — Create a 3D object model that represents a cylinder.

- [`GenEmptyObjectModel3d`](gen_empty_object_model_3d.md) — Create an empty 3D object model.

- [`GenObjectModel3dFromPoints`](gen_object_model_3d_from_points.md) — Create a 3D object model that represents a point cloud from a set of 3D points.

- [`GenPlaneObjectModel3d`](gen_plane_object_model_3d.md) — Create a 3D object model that represents a plane.

- [`GenSphereObjectModel3d`](gen_sphere_object_model_3d.md) — Create a 3D object model that represents a sphere.

- [`GenSphereObjectModel3dCenter`](gen_sphere_object_model_3d_center.md) — Create a 3D object model that represents a sphere from x,y,z coordinates.

- [`ReadObjectModel3d`](read_object_model_3d.md) — Read a 3D object model from a file.

- [`RemoveObjectModel3dAttrib`](remove_object_model_3d_attrib.md) — Remove attributes of a 3D object model.

- [`RemoveObjectModel3dAttribMod`](remove_object_model_3d_attrib_mod.md) — Remove attributes of a 3D object model.

- [`SerializeObjectModel3d`](serialize_object_model_3d.md) — Serialize a 3D object model.

- [`SetObjectModel3dAttrib`](set_object_model_3d_attrib.md) — Set attributes of a 3D object model.

- [`SetObjectModel3dAttribMod`](set_object_model_3d_attrib_mod.md) — Set attributes of a 3D object model.

- [`UnionObjectModel3d`](union_object_model_3d.md) — Combine several 3D object models to a new 3D object model.

- [`WriteObjectModel3d`](write_object_model_3d.md) — Writes a 3D object model to a file.
