## OCR

#### List of Operators

- [`CloseOcr`](close_ocr.md) — Deallocation of the memory of an OCR classifier.

- [`OcrGetFeatures`](ocr_get_features.md) — Access the features which correspond to a character.

- [`SerializeOcr`](serialize_ocr.md) — Serialize an OCR classifier.

- [`TestdOcrClassBox`](testd_ocr_class_box.md) — Test an OCR classifier.

- [`TraindOcrClassBox`](traind_ocr_class_box.md) — Train an OCR classifier by the input of regions.

- [`TrainfOcrClassBox`](trainf_ocr_class_box.md) — Train an OCR classifier with the help of a training file.

- [`WriteOcr`](write_ocr.md) — Writing an OCR classifier into a file.
