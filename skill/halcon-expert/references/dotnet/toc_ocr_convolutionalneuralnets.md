## Convolutional Neural Networks

#### List of Operators

- [`ClearOcrClassCnn`](clear_ocr_class_cnn.md) — Clear an CNN-based OCR classifier.

- [`DeserializeOcrClassCnn`](deserialize_ocr_class_cnn.md) — Deserialize a serialized CNN-based OCR classifier.

- [`DoOcrMultiClassCnn`](do_ocr_multi_class_cnn.md) — Classify multiple characters with an CNN-based OCR classifier.

- [`DoOcrSingleClassCnn`](do_ocr_single_class_cnn.md) — Classify a single character with an CNN-based OCR classifier.

- [`DoOcrWordCnn`](do_ocr_word_cnn.md) — Classify a related group of characters with an CNN-based OCR classifier.

- [`GetParamsOcrClassCnn`](get_params_ocr_class_cnn.md) — Return the parameters of a CNN-based OCR classifier.

- [`QueryParamsOcrClassCnn`](query_params_ocr_class_cnn.md) — Get the names of the parameters that can be used in
  [`GetParamsOcrClassCnn`](get_params_ocr_class_cnn.md)
  for a given CNN-based OCR classifier.

- [`ReadOcrClassCnn`](read_ocr_class_cnn.md) — Read an CNN-based OCR classifier from a file.

- [`SerializeOcrClassCnn`](serialize_ocr_class_cnn.md) — Serialize a CNN-based OCR classifier
