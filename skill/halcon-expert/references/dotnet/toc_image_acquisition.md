## Acquisition

#### List of Operators

- [`CloseFramegrabber`](close_framegrabber.md) — Close specified image acquisition device.

- [`GetFramegrabberCallback`](get_framegrabber_callback.md) — Query callback function of an image acquisition device.

- [`GetFramegrabberLut`](get_framegrabber_lut.md) — Query look-up table of the image acquisition device.

- [`GetFramegrabberParam`](get_framegrabber_param.md) — Query specific parameters of an image acquisition device.

- [`GrabData`](grab_data.md) — Synchronous grab of images and preprocessed image data from the specified
  image acquisition device.

- [`GrabDataAsync`](grab_data_async.md) — Asynchronous grab of images and preprocessed image data from the specified
  image acquisition device.

- [`GrabImage`](grab_image.md) — Synchronous grab of an image from the specified image acquisition device.

- [`GrabImageAsync`](grab_image_async.md) — Asynchronous grab of an image from the specified image acquisition device.

- [`GrabImageStart`](grab_image_start.md) — Start an asynchronous grab from the specified image acquisition device.

- [`InfoFramegrabber`](info_framegrabber.md) — Query information about the specified image acquisition interface.

- [`OpenFramegrabber`](open_framegrabber.md) — Open and configure an image acquisition device.

- [`SetFramegrabberCallback`](set_framegrabber_callback.md) — Register a callback function for an image acquisition device.

- [`SetFramegrabberLut`](set_framegrabber_lut.md) — Set look-up table of the image acquisition device.

- [`SetFramegrabberParam`](set_framegrabber_param.md) — Set specific parameters of an image acquisition device.
