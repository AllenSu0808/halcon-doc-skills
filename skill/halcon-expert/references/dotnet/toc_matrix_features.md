## Features

#### List of Operators

- [`DeterminantMatrix`](determinant_matrix.md) — Compute the determinant of a matrix.

- [`GetSizeMatrix`](get_size_matrix.md) — Get the size of a matrix.

- [`MaxMatrix`](max_matrix.md) — Returns the elementwise maximum of a matrix.

- [`MeanMatrix`](mean_matrix.md) — Returns the elementwise mean of a matrix.

- [`MinMatrix`](min_matrix.md) — Returns the elementwise minimum of a matrix.

- [`NormMatrix`](norm_matrix.md) — Norm of a matrix.

- [`SumMatrix`](sum_matrix.md) — Returns the elementwise sum of a matrix.
