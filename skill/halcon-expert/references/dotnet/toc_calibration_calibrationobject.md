## Calibration Object

#### List of Operators

- [`CaltabPoints`](caltab_points.md) — Read the mark center points from the calibration plate description file.

- [`CreateCaltab`](create_caltab.md) — Generate a calibration plate description file and a corresponding
  PostScript file for a calibration plate with hexagonally arranged marks.

- [`DispCaltab`](disp_caltab.md) — Project and visualize the 3D model of the calibration plate in the image.

- [`FindCalibObject`](find_calib_object.md) — Find the HALCON calibration plate and set the extracted points and
  contours in a calibration data model.

- [`FindCaltab`](find_caltab.md) — Segment the region of a standard calibration plate with rectangularly
  arranged marks in the image.

- [`FindMarksAndPose`](find_marks_and_pose.md) — Extract rectangularly arranged 2D calibration marks from the image and
  calculate initial values for the external camera parameters.

- [`GenCaltab`](gen_caltab.md) — Generate a calibration plate description file and a corresponding
  PostScript file for a calibration plate with rectangularly arranged marks.

- [`SimCaltab`](sim_caltab.md) — Simulate an image with calibration plate.
