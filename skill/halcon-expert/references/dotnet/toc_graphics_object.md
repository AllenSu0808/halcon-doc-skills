## Object

#### List of Operators

- [`AttachBackgroundToWindow`](attach_background_to_window.md) — Attach a background image to a HALCON window.

- [`AttachDrawingObjectToWindow`](attach_drawing_object_to_window.md) — Attach an existing drawing object to a HALCON window.

- [`ClearDrawingObject`](clear_drawing_object.md) — Delete drawing object.

- [`CreateDrawingObjectCircle`](create_drawing_object_circle.md) — Create a circle which can be modified interactively.

- [`CreateDrawingObjectCircleSector`](create_drawing_object_circle_sector.md) — Create a circle sector which can be modified interactively.

- [`CreateDrawingObjectEllipse`](create_drawing_object_ellipse.md) — Create an ellipse which can be modified interactively.

- [`CreateDrawingObjectEllipseSector`](create_drawing_object_ellipse_sector.md) — Create an elliptic sector which can be modified interactively.

- [`CreateDrawingObjectLine`](create_drawing_object_line.md) — Create a line which can be modified interactively.

- [`CreateDrawingObjectRectangle1`](create_drawing_object_rectangle1.md) — Create a rectangle parallel to the coordinate axis which can be
  modified interactively.

- [`CreateDrawingObjectRectangle2`](create_drawing_object_rectangle2.md) — Create a rectangle of any orientation which can be modified interactively.

- [`CreateDrawingObjectText`](create_drawing_object_text.md) — Create a text object which can be moved interactively.

- [`CreateDrawingObjectXld`](create_drawing_object_xld.md) — Create a XLD contour which can be modified interactively.

- [`DetachBackgroundFromWindow`](detach_background_from_window.md) — Detach the background image from a HALCON window.

- [`DetachDrawingObjectFromWindow`](detach_drawing_object_from_window.md) — Detach an existing drawing object from a HALCON window.

- [`GetDrawingObjectIconic`](get_drawing_object_iconic.md) — Return the iconic object of a drawing object.

- [`GetDrawingObjectParams`](get_drawing_object_params.md) — Get the parameters of a drawing object.

- [`GetWindowBackgroundImage`](get_window_background_image.md) — Gets a copy of the background image of the HALCON window.

- [`SetContentUpdateCallback`](set_content_update_callback.md) — Sets the callback for content updates in buffer window.

- [`SetDrawingObjectCallback`](set_drawing_object_callback.md) — Add a callback function to a drawing object.

- [`SetDrawingObjectParams`](set_drawing_object_params.md) — Set the parameters of a drawing object.

- [`SetDrawingObjectXld`](set_drawing_object_xld.md) — Set the contour of an interactive draw XLD.
