## Background Estimator

#### List of Operators

- [`CloseBgEsti`](close_bg_esti.md) — Delete the background estimation data set.

- [`CreateBgEsti`](create_bg_esti.md) — Generate and initialize a data set for the background estimation.

- [`GetBgEstiParams`](get_bg_esti_params.md) — Return the parameters of the data set.

- [`GiveBgEsti`](give_bg_esti.md) — Return the estimated background image.

- [`RunBgEsti`](run_bg_esti.md) — Estimate the background and return the foreground region.

- [`SetBgEstiParams`](set_bg_esti_params.md) — Change the parameters of the data set.

- [`UpdateBgEsti`](update_bg_esti.md) — Change the estimated background image.
