## Correlation-Based

#### List of Operators

- [`ClearNccModel`](clear_ncc_model.md) — Free the memory of an NCC model.

- [`CreateNccModel`](create_ncc_model.md) — Prepare an NCC model for matching.

- [`DeserializeNccModel`](deserialize_ncc_model.md) — Deserialize an NCC model.

- [`DetermineNccModelParams`](determine_ncc_model_params.md) — Determine the parameters of an NCC model.

- [`FindNccModel`](find_ncc_model.md) — Find the best matches of an NCC model in an image.

- [`FindNccModels`](find_ncc_models.md) — Find the best matches of multiple NCC models.

- [`GetNccModelOrigin`](get_ncc_model_origin.md) — Return the origin (reference point) of an NCC model.

- [`GetNccModelParams`](get_ncc_model_params.md) — Return the parameters of an NCC model.

- [`GetNccModelRegion`](get_ncc_model_region.md) — Return the region used to create an NCC model.

- [`ReadNccModel`](read_ncc_model.md) — Read an NCC model from a file.

- [`SerializeNccModel`](serialize_ncc_model.md) — Serialize an NCC model.

- [`SetNccModelOrigin`](set_ncc_model_origin.md) — Set the origin (reference point) of an NCC model.

- [`SetNccModelParam`](set_ncc_model_param.md) — Set selected parameters of the NCC model.

- [`WriteNccModel`](write_ncc_model.md) — Write an NCC model to a file.
