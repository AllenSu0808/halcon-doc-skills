## Grid Rectification

#### List of Operators

- [`ConnectGridPoints`](connect_grid_points.md) — Establish connections between the grid points of the rectification grid.

- [`CreateRectificationGrid`](create_rectification_grid.md) — Generate a PostScript file, which describes the rectification grid.

- [`FindRectificationGrid`](find_rectification_grid.md) — Segment the rectification grid region in the image.

- [`GenArbitraryDistortionMap`](gen_arbitrary_distortion_map.md) — Generate a projection map that describes the mapping between an arbitrarily
  distorted image and the rectified image.

- [`GenGridRectificationMap`](gen_grid_rectification_map.md) — Compute the mapping between the distorted image and the rectified image
  based upon the points of a regular grid.
