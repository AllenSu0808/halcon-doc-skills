## Access

#### List of Operators

- [`GetContourXld`](get_contour_xld.md) — Return the coordinates of an XLD contour.

- [`GetLinesXld`](get_lines_xld.md) — Return an XLD polygon's data (as lines).

- [`GetParallelsXld`](get_parallels_xld.md) — Return an XLD parallel's data (as lines).

- [`GetPolygonXld`](get_polygon_xld.md) — Return an XLD polygon's data.
