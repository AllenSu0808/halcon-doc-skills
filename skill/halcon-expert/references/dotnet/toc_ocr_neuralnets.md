## Neural Nets

#### List of Operators

- [`ClearOcrClassMlp`](clear_ocr_class_mlp.md) — Clear an OCR classifier.

- [`CreateOcrClassMlp`](create_ocr_class_mlp.md) — Create an OCR classifier using a multilayer perceptron.

- [`DeserializeOcrClassMlp`](deserialize_ocr_class_mlp.md) — Deserialize a serialized MLP-based OCR classifier.

- [`DoOcrMultiClassMlp`](do_ocr_multi_class_mlp.md) — Classify multiple characters with an OCR classifier.

- [`DoOcrSingleClassMlp`](do_ocr_single_class_mlp.md) — Classify a single character with an OCR classifier.

- [`DoOcrWordMlp`](do_ocr_word_mlp.md) — Classify a related group of characters with an OCR classifier.

- [`GetFeaturesOcrClassMlp`](get_features_ocr_class_mlp.md) — Compute the features of a character.

- [`GetParamsOcrClassMlp`](get_params_ocr_class_mlp.md) — Return the parameters of an OCR classifier.

- [`GetPrepInfoOcrClassMlp`](get_prep_info_ocr_class_mlp.md) — Compute the information content of the preprocessed feature vectors
  of an OCR classifier.

- [`GetRegularizationParamsOcrClassMlp`](get_regularization_params_ocr_class_mlp.md) — Return the regularization parameters of an OCR classifier.

- [`GetRejectionParamsOcrClassMlp`](get_rejection_params_ocr_class_mlp.md) — Return the rejection class parameters of an OCR classifier.

- [`ReadOcrClassMlp`](read_ocr_class_mlp.md) — Read an OCR classifier from a file.

- [`SelectFeatureSetTrainfMlp`](select_feature_set_trainf_mlp.md) — Selects an optimal combination of features to classify OCR data.

- [`SelectFeatureSetTrainfMlpProtected`](select_feature_set_trainf_mlp_protected.md) — Select an optimal combination of features to classify OCR data
  from a (protected) training file.

- [`SerializeOcrClassMlp`](serialize_ocr_class_mlp.md) — Serialize a MLP-based OCR classifier.

- [`SetRegularizationParamsOcrClassMlp`](set_regularization_params_ocr_class_mlp.md) — Set the regularization parameters of an OCR classifier.

- [`SetRejectionParamsOcrClassMlp`](set_rejection_params_ocr_class_mlp.md) — Set the rejection class parameters of an OCR classifier.

- [`TrainfOcrClassMlp`](trainf_ocr_class_mlp.md) — Train an OCR classifier.

- [`TrainfOcrClassMlpProtected`](trainf_ocr_class_mlp_protected.md) — Train an OCR classifier with data from a (protected) training file.

- [`WriteOcrClassMlp`](write_ocr_class_mlp.md) — Write an OCR classifier to a file.
