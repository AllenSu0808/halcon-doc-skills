## Creation

#### List of Operators

- [`CopyImage`](copy_image.md) — Copy an image and allocate new memory for it.

- [`GenImage1`](gen_image1.md) — Create an image from a pointer to the pixels.

- [`GenImage1Extern`](gen_image1_extern.md) — Create an image from a pointer on the pixels with storage management.

- [`GenImage1Rect`](gen_image1_rect.md) — Create an image with a rectangular domain from a pointer on the pixels
  (with storage management).

- [`GenImage3`](gen_image3.md) — Create an image from three pointers to the pixels (red/green/blue).

- [`GenImage3Extern`](gen_image3_extern.md) — Create a three-channel image from three pointers on the pixels with storage
  management.

- [`GenImageConst`](gen_image_const.md) — Create an image with constant gray value.

- [`GenImageGrayRamp`](gen_image_gray_ramp.md) — Create a gray value ramp.

- [`GenImageInterleaved`](gen_image_interleaved.md) — Create a three-channel image from a pointer to the interleaved pixels.

- [`GenImageProto`](gen_image_proto.md) — Create an image with a specified constant gray value.

- [`GenImageSurfaceFirstOrder`](gen_image_surface_first_order.md) — Create a tilted gray surface with first order polynomial.

- [`GenImageSurfaceSecondOrder`](gen_image_surface_second_order.md) — Create a curved gray surface with second order polynomial.

- [`InterleaveChannels`](interleave_channels.md) — Create an interleaved image from a multichannel image.

- [`RegionToBin`](region_to_bin.md) — Convert a region into a binary byte-image.

- [`RegionToLabel`](region_to_label.md) — Convert regions to a label image.

- [`RegionToMean`](region_to_mean.md) — Paint regions with their average gray value.
