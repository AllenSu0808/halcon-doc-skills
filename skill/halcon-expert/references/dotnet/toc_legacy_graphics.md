## Graphics

#### List of Operators

- [`ClearRectangle`](clear_rectangle.md) — Delete a rectangle on the output window.

- [`DispDistribution`](disp_distribution.md) — Displays a noise distribution.

- [`DispLut`](disp_lut.md) — Graphical view of the look-up-table (lut).

- [`GetComprise`](get_comprise.md) — Get the output treatment of an image matrix.

- [`GetFix`](get_fix.md) — Get mode of fixing of current look-up-table (lut).

- [`GetFixedLut`](get_fixed_lut.md) — Get fixing of “look-up-table” (lut) for “real color images”

- [`GetLineApprox`](get_line_approx.md) — Get the current approximation error for contour display.

- [`GetLutStyle`](get_lut_style.md) — Get modification parameters of look-up-table (lut).

- [`GetPixel`](get_pixel.md) — Get the current color lookup table index.

- [`GetTshape`](get_tshape.md) — Get the shape of the text cursor.

- [`MoveRectangle`](move_rectangle.md) — Copy inside an output window.

- [`OpenTextwindow`](open_textwindow.md) — Open a textual window.

- [`QueryTshape`](query_tshape.md) — Query all shapes available for text cursors.

- [`SetComprise`](set_comprise.md) — Define the image matrix output clipping.

- [`SetFix`](set_fix.md) — Set fixing of “look-up-table” (lut)

- [`SetFixedLut`](set_fixed_lut.md) — Fix “look-up-table” (lut) for “real color images”.

- [`SetLineApprox`](set_line_approx.md) — Define the approximation error for contour display.

- [`SetLutStyle`](set_lut_style.md) — Changing the look-up-table (lut).

- [`SetPixel`](set_pixel.md) — Define a color lookup table index.

- [`SetTshape`](set_tshape.md) — Set the shape of the text cursor.

- [`SlideImage`](slide_image.md) — Interactive output from two window buffers.

- [`WriteLut`](write_lut.md) — Write look-up-table (lut) as file.
