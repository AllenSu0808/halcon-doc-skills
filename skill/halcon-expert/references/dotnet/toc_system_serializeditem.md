## Serialized Item

#### List of Operators

- [`ClearSerializedItem`](clear_serialized_item.md) — Delete a serialized item.

- [`CreateSerializedItemPtr`](create_serialized_item_ptr.md) — Create a serialized item.

- [`DecryptSerializedItem`](decrypt_serialized_item.md) — Decrypt an encrypted item.

- [`EncryptSerializedItem`](encrypt_serialized_item.md) — Encrypt a serialized item.

- [`FreadSerializedItem`](fread_serialized_item.md) — Read a serialized item from a file.

- [`FwriteSerializedItem`](fwrite_serialized_item.md) — Write a serialized item to a file.

- [`GetSerializedItemPtr`](get_serialized_item_ptr.md) — Access the data pointer of a serialized item.
