## Support Vector Machines

#### List of Operators

- [`AddClassTrainDataSvm`](add_class_train_data_svm.md) — Add training data to a support vector machine (SVM).

- [`AddSampleClassSvm`](add_sample_class_svm.md) — Add a training sample to the training data of a support vector
  machine.

- [`ClassifyClassSvm`](classify_class_svm.md) — Classify a feature vector by a support vector machine.

- [`ClearClassSvm`](clear_class_svm.md) — Clear a support vector machine.

- [`ClearSamplesClassSvm`](clear_samples_class_svm.md) — Clear the training data of a support vector machine.

- [`CreateClassSvm`](create_class_svm.md) — Create a support vector machine for pattern classification.

- [`DeserializeClassSvm`](deserialize_class_svm.md) — Deserialize a serialized support vector machine (SVM).

- [`EvaluateClassSvm`](evaluate_class_svm.md) — Evaluate a feature vector by a support vector machine.

- [`GetClassTrainDataSvm`](get_class_train_data_svm.md) — Get the training data of a support vector machine (SVM).

- [`GetParamsClassSvm`](get_params_class_svm.md) — Return the parameters of a support vector machine.

- [`GetPrepInfoClassSvm`](get_prep_info_class_svm.md) — Compute the information content of the preprocessed feature vectors
  of a support vector machine

- [`GetSampleClassSvm`](get_sample_class_svm.md) — Return a training sample from the training data of a support vector
  machine.

- [`GetSampleNumClassSvm`](get_sample_num_class_svm.md) — Return the number of training samples stored in the training data of
  a support vector machine.

- [`GetSupportVectorClassSvm`](get_support_vector_class_svm.md) — Return the index of a support vector from a trained support vector
  machine.

- [`GetSupportVectorNumClassSvm`](get_support_vector_num_class_svm.md) — Return the number of support vectors of a support vector machine.

- [`ReadClassSvm`](read_class_svm.md) — Read a support vector machine from a file.

- [`ReadSamplesClassSvm`](read_samples_class_svm.md) — Read the training data of a support vector machine from a file.

- [`ReduceClassSvm`](reduce_class_svm.md) — Approximate a trained support vector machine by a reduced support
  vector machine for faster classification.

- [`SelectFeatureSetSvm`](select_feature_set_svm.md) — Selects an optimal combination of features to classify the provided data.

- [`SerializeClassSvm`](serialize_class_svm.md) — Serialize a support vector machine (SVM).

- [`TrainClassSvm`](train_class_svm.md) — Train a support vector machine.

- [`WriteClassSvm`](write_class_svm.md) — Write a support vector machine to a file.

- [`WriteSamplesClassSvm`](write_samples_class_svm.md) — Write the training data of a support vector machine to a file.
