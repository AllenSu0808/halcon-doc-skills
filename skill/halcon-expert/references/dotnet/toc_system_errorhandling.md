## Error Handling

#### List of Operators

- [`GetCheck`](get_check.md) — State of the HALCON control modes.

- [`GetErrorText`](get_error_text.md) — Inquiry after the error text of a HALCON error number.

- [`GetExtendedErrorInfo`](get_extended_error_info.md) — Returns the extended error information for the calling thread's last
  HALCON error.

- [`GetSpy`](get_spy.md) — Current configuration of the HALCON debugging-tool.

- [`QuerySpy`](query_spy.md) — Inquiring for possible settings of the HALCON debugging tool.

- [`SetCheck`](set_check.md) — Activating and deactivating of HALCON control modes.

- [`SetSpy`](set_spy.md) — Control of the HALCON Debugging Tools.
