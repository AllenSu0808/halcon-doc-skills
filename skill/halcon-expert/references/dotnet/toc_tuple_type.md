## Type

#### List of Operators

- [`TupleIsHandle`](tuple_is_handle.md) — Test if the internal representation of a tuple is of type `handle`.

- [`TupleIsHandleElem`](tuple_is_handle_elem.md) — Test whether the elements of a tuple are of type `handle`.

- [`TupleIsInt`](tuple_is_int.md) — Test if the internal representation of a tuple is of type `integer`.

- [`TupleIsIntElem`](tuple_is_int_elem.md) — Test whether the types of the elements of a tuple are of type
  `integer`.

- [`TupleIsMixed`](tuple_is_mixed.md) — Test whether a tuple is of type `mixed`.

- [`TupleIsNanElem`](tuple_is_nan_elem.md) — Check a tuple whether it represents NaNs (Not-a-number).

- [`TupleIsNumber`](tuple_is_number.md) — Check a tuple (of strings) whether it represents numbers.

- [`TupleIsReal`](tuple_is_real.md) — Test if the internal representation of a tuple is of type `real`.

- [`TupleIsRealElem`](tuple_is_real_elem.md) — Test whether the types of the elements of a tuple are of type `real`.

- [`TupleIsString`](tuple_is_string.md) — Test if the internal representation of a tuple is of type `string`.

- [`TupleIsStringElem`](tuple_is_string_elem.md) — Test whether the types of the elements of a tuple are of type
  `string`.

- [`TupleIsValidHandle`](tuple_is_valid_handle.md) — Check if a handle is valid.

- [`TupleSemType`](tuple_sem_type.md) — Return the semantic type of a tuple.

- [`TupleSemTypeElem`](tuple_sem_type_elem.md) — Return the semantic type of the elements of a tuple.

- [`TupleType`](tuple_type.md) — Return the type of a tuple.

- [`TupleTypeElem`](tuple_type_elem.md) — Return the types of the elements of a tuple.
