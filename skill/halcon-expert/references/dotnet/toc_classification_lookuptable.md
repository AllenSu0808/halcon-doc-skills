## Look-Up Table

#### List of Operators

- [`ClearClassLut`](clear_class_lut.md) — Clear a look-up table classifier.

- [`CreateClassLutGmm`](create_class_lut_gmm.md) — Create a look-up table using a Gaussian mixture model to classify byte
  images.

- [`CreateClassLutKnn`](create_class_lut_knn.md) — Create a look-up table using a k-nearest neighbors
  classifier (k-NN) to classify byte
  images.

- [`CreateClassLutMlp`](create_class_lut_mlp.md) — Create a look-up table using a multi-layer perceptron to classify byte
  images.

- [`CreateClassLutSvm`](create_class_lut_svm.md) — Create a look-up table using a Support-Vector-Machine to classify byte
  images.
