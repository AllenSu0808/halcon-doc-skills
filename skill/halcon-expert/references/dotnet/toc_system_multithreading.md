## Multithreading

#### List of Operators

- [`BroadcastCondition`](broadcast_condition.md) — Signal a condition synchronization object.

- [`ClearBarrier`](clear_barrier.md) — Destroy a barrier synchronization object.

- [`ClearCondition`](clear_condition.md) — Destroy a condition synchronization object.

- [`ClearEvent`](clear_event.md) — Clear the event synchronization object.

- [`ClearMessage`](clear_message.md) — Close a message handle and release all associated resources.

- [`ClearMessageQueue`](clear_message_queue.md) — Close a message queue handle and release all associated resources.

- [`ClearMutex`](clear_mutex.md) — Clear the mutex synchronization object.

- [`CreateBarrier`](create_barrier.md) — Create a barrier synchronization object.

- [`CreateCondition`](create_condition.md) — Create a condition variable synchronization object.

- [`CreateEvent`](create_event.md) — Create an event synchronization object.

- [`CreateMessage`](create_message.md) — Create a new empty message.

- [`CreateMessageQueue`](create_message_queue.md) — Create a new empty message queue.

- [`CreateMutex`](create_mutex.md) — Create a mutual exclusion synchronization object.

- [`DequeueMessage`](dequeue_message.md) — Receive one or more messages from the message queue.

- [`EnqueueMessage`](enqueue_message.md) — Enqueue one or more messages to the message queue.

- [`GetCurrentHthreadId`](get_current_hthread_id.md) — Return the HALCON thread ID of the current thread.

- [`GetMessageObj`](get_message_obj.md) — Retrieve an object associated with the key from the message.

- [`GetMessageParam`](get_message_param.md) — Query message parameters or information about the message.

- [`GetMessageQueueParam`](get_message_queue_param.md) — Query message queue parameters or information about the queue.

- [`GetMessageTuple`](get_message_tuple.md) — Retrieve a tuple associated with the key from the message.

- [`GetThreadingAttrib`](get_threading_attrib.md) — Query the attributes of a threading / synchronization object.

- [`InterruptOperator`](interrupt_operator.md) — Attempt to interrupt an operator running in a different thread.

- [`LockMutex`](lock_mutex.md) — Lock a mutex synchronization object.

- [`ReadMessage`](read_message.md) — Read a message from a file.

- [`SetMessageObj`](set_message_obj.md) — Add a key/object pair to the message.

- [`SetMessageParam`](set_message_param.md) — Set message parameter or invoke commands on the message.

- [`SetMessageQueueParam`](set_message_queue_param.md) — Set message queue parameters or invoke commands on the queue.

- [`SetMessageTuple`](set_message_tuple.md) — Add a key/tuple pair to the message.

- [`SignalCondition`](signal_condition.md) — Signal a condition synchronization object.

- [`SignalEvent`](signal_event.md) — Unlock an event synchronization object.

- [`TimedWaitCondition`](timed_wait_condition.md) — Bounded wait on the signal of a condition synchronization object.

- [`TryLockMutex`](try_lock_mutex.md) — Lock a mutex synchronization object.

- [`TryWaitEvent`](try_wait_event.md) — Lock an event synchronization object only if it is unlocked.

- [`UnlockMutex`](unlock_mutex.md) — Unlock a mutex synchronization object.

- [`WaitBarrier`](wait_barrier.md) — Wait on the release of a barrier synchronization object.

- [`WaitCondition`](wait_condition.md) — wait on the signal of a condition synchronization object.

- [`WaitEvent`](wait_event.md) — Lock an event synchronization object.

- [`WriteMessage`](write_message.md) — Write a message to a file.
