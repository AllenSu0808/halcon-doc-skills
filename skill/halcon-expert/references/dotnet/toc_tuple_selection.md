## Selection

#### List of Operators

- [`TupleFind`](tuple_find.md) — Return the indices of all occurrences of a tuple within another tuple.

- [`TupleFindFirst`](tuple_find_first.md) — Return the index of the first occurrence of a tuple within another tuple.

- [`TupleFindLast`](tuple_find_last.md) — Return the index of the last occurrence of a tuple within another tuple.

- [`TupleFirstN`](tuple_first_n.md) — Select the first elements of a tuple up to the index “n”.

- [`TupleLastN`](tuple_last_n.md) — Select all elements from index “n” to the end of a tuple.

- [`TupleSelect`](tuple_select.md) — Select single elements of a tuple.

- [`TupleSelectMask`](tuple_select_mask.md) — Select in mask specified elements of a tuple.

- [`TupleSelectRange`](tuple_select_range.md) — Select several elements of a tuple.

- [`TupleSelectRank`](tuple_select_rank.md) — Select the element of rank n of a tuple.

- [`TupleStrBitSelect`](tuple_str_bit_select.md) — Select single character or bit from a tuple.

- [`TupleUniq`](tuple_uniq.md) — Discard all but one of successive identical elements of a tuple.
