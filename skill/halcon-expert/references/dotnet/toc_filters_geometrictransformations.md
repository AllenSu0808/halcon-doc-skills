## Geometric Transformations

#### List of Operators

- [`AffineTransImage`](affine_trans_image.md) — Apply an arbitrary affine 2D transformation to images.

- [`AffineTransImageSize`](affine_trans_image_size.md) — Apply an arbitrary affine 2D transformation to an image and specify
  the output image size.

- [`ConvertMapType`](convert_map_type.md) — Convert image maps into other map types.

- [`MapImage`](map_image.md) — Apply a general transformation to an image.

- [`MirrorImage`](mirror_image.md) — Mirror an image.

- [`PolarTransImageExt`](polar_trans_image_ext.md) — Transform an annular arc in an image to polar coordinates.

- [`PolarTransImageInv`](polar_trans_image_inv.md) — Transform an image in polar coordinates back to Cartesian coordinates

- [`ProjectiveTransImage`](projective_trans_image.md) — Apply a projective transformation to an image.

- [`ProjectiveTransImageSize`](projective_trans_image_size.md) — Apply a projective transformation to an image and specify the output
  image size.

- [`RotateImage`](rotate_image.md) — Rotate an image about its center.

- [`ZoomImageFactor`](zoom_image_factor.md) — Zoom an image by a given factor.

- [`ZoomImageSize`](zoom_image_size.md) — Zoom an image to a given size.
