## Creation

#### List of Operators

- [`GenCircleContourXld`](gen_circle_contour_xld.md) — Create XLD contours corresponding to circles or circular arcs.

- [`GenContourNurbsXld`](gen_contour_nurbs_xld.md) — Transform a NURBS curve into an XLD contour.

- [`GenContourPolygonRoundedXld`](gen_contour_polygon_rounded_xld.md) — Generate an XLD contour with rounded corners from a polygon (given
  as tuples).

- [`GenContourPolygonXld`](gen_contour_polygon_xld.md) — Generate an XLD contour from a polygon (given as tuples).

- [`GenContourRegionXld`](gen_contour_region_xld.md) — Generate XLD contours from regions.

- [`GenContoursSkeletonXld`](gen_contours_skeleton_xld.md) — Convert a skeleton into XLD contours.

- [`GenCrossContourXld`](gen_cross_contour_xld.md) — Generate one XLD contour in the shape of a cross for each input point.

- [`GenEllipseContourXld`](gen_ellipse_contour_xld.md) — Create an XLD contour that corresponds to an elliptic arc.

- [`GenNurbsInterp`](gen_nurbs_interp.md) — Create control data of a NURBS curve that interpolates given points.

- [`GenParallelsXld`](gen_parallels_xld.md) — Extract parallel XLD polygons.

- [`GenPolygonsXld`](gen_polygons_xld.md) — Approximate XLD contours by polygons.

- [`GenRectangle2ContourXld`](gen_rectangle2_contour_xld.md) — Create an XLD contour in the shape of a rectangle.

- [`ModParallelsXld`](mod_parallels_xld.md) — Extract parallel XLD polygons enclosing a homogeneous area.
