# HOCRSvm (Class)

## Name

`HOCRSvm` — Represents an instance of a SVM OCR classifier.

## Constructors

|  |  |  |
| --- | --- | --- |
| `ReadOcrClassSvm` |  | Read a SVM-based OCR classifier from a file. |
| `CreateOcrClassSvm` |  | Create an OCR classifier using a support vector machine. |
