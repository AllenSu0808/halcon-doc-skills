## Matching, Component-Based

#### List of Operators

- [`ClearComponentModel`](clear_component_model.md) — Free the memory of a component model.

- [`ClearTrainingComponents`](clear_training_components.md) — Free the memory of a component training result.

- [`ClusterModelComponents`](cluster_model_components.md) — Adopt new parameters that are used to create the model components into the
  training result.

- [`CreateComponentModel`](create_component_model.md) — Prepare a component model for matching based on explicitly specified
  components and relations.

- [`CreateTrainedComponentModel`](create_trained_component_model.md) — Prepare a component model for matching based on trained components.

- [`DeserializeComponentModel`](deserialize_component_model.md) — Deserialize a serialized component model.

- [`DeserializeTrainingComponents`](deserialize_training_components.md) — Deserialize a component training result.

- [`FindComponentModel`](find_component_model.md) — Find the best matches of a component model in an image.

- [`GenInitialComponents`](gen_initial_components.md) — Extract the initial components of a component model.

- [`GetComponentModelParams`](get_component_model_params.md) — Return the parameters of a component model.

- [`GetComponentModelTree`](get_component_model_tree.md) — Return the search tree of a component model.

- [`GetComponentRelations`](get_component_relations.md) — Return the relations between the model components that are contained in
  a training result.

- [`GetFoundComponentModel`](get_found_component_model.md) — Return the components of a found instance of a component model.

- [`GetTrainingComponents`](get_training_components.md) — Return the initial or model components in a certain image.

- [`InspectClusteredComponents`](inspect_clustered_components.md) — Inspect the rigid model components obtained from the training.

- [`ModifyComponentRelations`](modify_component_relations.md) — Modify the relations within a training result.

- [`ReadComponentModel`](read_component_model.md) — Read a component model from a file.

- [`ReadTrainingComponents`](read_training_components.md) — Read a component training result from a file.

- [`SerializeComponentModel`](serialize_component_model.md) — Serialize a component model.

- [`SerializeTrainingComponents`](serialize_training_components.md) — Serialize a component training result.

- [`TrainModelComponents`](train_model_components.md) — Train components and relations for the component-based matching.

- [`WriteComponentModel`](write_component_model.md) — Write a component model to a file.

- [`WriteTrainingComponents`](write_training_components.md) — Write a component training result to a file.
