## Transformations

#### List of Operators

- [`AffineTransObjectModel3d`](affine_trans_object_model_3d.md) — Apply an arbitrary affine 3D transformation to 3D object models.

- [`ConnectionObjectModel3d`](connection_object_model_3d.md) — Determine the connected components of the
  3D object model.

- [`ConvexHullObjectModel3d`](convex_hull_object_model_3d.md) — Calculate the convex hull of a 3D object model.

- [`EdgesObjectModel3d`](edges_object_model_3d.md) — Find edges in a 3D object model.

- [`FuseObjectModel3d`](fuse_object_model_3d.md) — Fuse 3D object models into a surface.

- [`IntersectPlaneObjectModel3d`](intersect_plane_object_model_3d.md) — Intersect a 3D object model with a plane.

- [`ObjectModel3dToXyz`](object_model_3d_to_xyz.md) — Transform 3D points from a 3D object model to images.

- [`PrepareObjectModel3d`](prepare_object_model_3d.md) — Prepare a 3D object model for a certain operation.

- [`ProjectObjectModel3d`](project_object_model_3d.md) — Project a 3D object model into image coordinates.

- [`ProjectiveTransObjectModel3d`](projective_trans_object_model_3d.md) — Apply an arbitrary projective 3D transformation to 3D object models.

- [`RegisterObjectModel3dGlobal`](register_object_model_3d_global.md) — Improve the relative transformations between 3D object models based on
  their overlaps.

- [`RegisterObjectModel3dPair`](register_object_model_3d_pair.md) — Search for a transformation between two 3D object models.

- [`RenderObjectModel3d`](render_object_model_3d.md) — Render 3D object models to get an image.

- [`RigidTransObjectModel3d`](rigid_trans_object_model_3d.md) — Apply a rigid 3D transformation to 3D object models.

- [`SampleObjectModel3d`](sample_object_model_3d.md) — Sample a 3D object model.

- [`SimplifyObjectModel3d`](simplify_object_model_3d.md) — Simplify a triangulated 3D object model.

- [`SmoothObjectModel3d`](smooth_object_model_3d.md) — Smooth the 3D points of a 3D object model.

- [`SurfaceNormalsObjectModel3d`](surface_normals_object_model_3d.md) — Calculate the 3D surface normals of a 3D object model.

- [`TriangulateObjectModel3d`](triangulate_object_model_3d.md) — Create a surface triangulation for a 3D object model.

- [`XyzToObjectModel3d`](xyz_to_object_model_3d.md) — Transform 3D points from images to a 3D object model.
