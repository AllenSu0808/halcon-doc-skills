## Tuple

#### List of Operators

- [`DeserializeHandle`](deserialize_handle.md) — Deserialize a serialized item.

- [`DeserializeTuple`](deserialize_tuple.md) — Deserialize a serialized tuple.

- [`ReadTuple`](read_tuple.md) — Read a tuple from a file.

- [`SerializeHandle`](serialize_handle.md) — Serialize the content of a handle.

- [`SerializeTuple`](serialize_tuple.md) — Serialize a tuple.

- [`TupleIsSerializable`](tuple_is_serializable.md) — Test if a tuple is serializable.

- [`TupleIsSerializableElem`](tuple_is_serializable_elem.md) — Test if the elements of a tuple are serializable.

- [`WriteTuple`](write_tuple.md) — Write a tuple to a file.
