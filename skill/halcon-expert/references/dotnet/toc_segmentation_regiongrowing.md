## Region Growing

#### List of Operators

- [`ExpandGray`](expand_gray.md) — Fill gaps between regions (depending on gray value or color) or split
  overlapping regions.

- [`ExpandGrayRef`](expand_gray_ref.md) — Fill gaps between regions (depending on gray value or color) or split
  overlapping regions.

- [`Regiongrowing`](regiongrowing.md) — Segment an image using region growing.

- [`RegiongrowingMean`](regiongrowing_mean.md) — Perform a region growing using mean gray values.

- [`RegiongrowingN`](regiongrowing_n.md) — Segment an image using region growing for multi-channel images.
