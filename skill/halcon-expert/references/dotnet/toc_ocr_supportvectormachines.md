## Support Vector Machines

#### List of Operators

- [`ClearOcrClassSvm`](clear_ocr_class_svm.md) — Clear an SVM-based OCR classifier.

- [`CreateOcrClassSvm`](create_ocr_class_svm.md) — Create an OCR classifier using a support vector machine.

- [`DeserializeOcrClassSvm`](deserialize_ocr_class_svm.md) — Deserialize a serialized SVM-based OCR classifier.

- [`DoOcrMultiClassSvm`](do_ocr_multi_class_svm.md) — Classify multiple characters with an SVM-based OCR classifier.

- [`DoOcrSingleClassSvm`](do_ocr_single_class_svm.md) — Classify a single character with an SVM-based OCR classifier.

- [`DoOcrWordSvm`](do_ocr_word_svm.md) — Classify a related group of characters with an OCR classifier.

- [`GetFeaturesOcrClassSvm`](get_features_ocr_class_svm.md) — Compute the features of a character.

- [`GetParamsOcrClassSvm`](get_params_ocr_class_svm.md) — Return the parameters of an OCR classifier.

- [`GetPrepInfoOcrClassSvm`](get_prep_info_ocr_class_svm.md) — Compute the information content of the preprocessed feature vectors
  of an SVM-based OCR classifier.

- [`GetSupportVectorNumOcrClassSvm`](get_support_vector_num_ocr_class_svm.md) — Return the number of support vectors of an OCR classifier.

- [`GetSupportVectorOcrClassSvm`](get_support_vector_ocr_class_svm.md) — Return the index of a support vector from a trained OCR classifier that is
  based on support vector machines.

- [`ReadOcrClassSvm`](read_ocr_class_svm.md) — Read a SVM-based OCR classifier from a file.

- [`ReduceOcrClassSvm`](reduce_ocr_class_svm.md) — Approximate a trained SVM-based OCR classifier by a reduced SVM.

- [`SelectFeatureSetTrainfSvm`](select_feature_set_trainf_svm.md) — Selects an optimal combination of features to classify OCR data.

- [`SelectFeatureSetTrainfSvmProtected`](select_feature_set_trainf_svm_protected.md) — Select an optimal combination of features to classify OCR data
  from a (protected) training file.

- [`SerializeOcrClassSvm`](serialize_ocr_class_svm.md) — Serialize a SVM-based OCR classifier

- [`TrainfOcrClassSvm`](trainf_ocr_class_svm.md) — Train an OCR classifier.

- [`TrainfOcrClassSvmProtected`](trainf_ocr_class_svm_protected.md) — Train an OCR classifier with data from a (protected) training file.

- [`WriteOcrClassSvm`](write_ocr_class_svm.md) — Write an OCR classifier to a file.
