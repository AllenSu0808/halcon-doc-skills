## Morphology

#### List of Operators

- [`ClosingGolay`](closing_golay.md) — Close a region with an element from the Golay alphabet.

- [`DilationGolay`](dilation_golay.md) — Dilate a region with an element from the Golay alphabet.

- [`DilationSeq`](dilation_seq.md) — Dilate a region sequentially.

- [`ErosionGolay`](erosion_golay.md) — Erode a region with an element from the Golay alphabet.

- [`ErosionSeq`](erosion_seq.md) — Erode a region sequentially.

- [`Fitting`](fitting.md) — Perform a closing after an opening with multiple structuring elements.

- [`GenStructElements`](gen_struct_elements.md) — Generate standard structuring elements.

- [`GolayElements`](golay_elements.md) — Generate the structuring elements of the Golay alphabet.

- [`HitOrMissGolay`](hit_or_miss_golay.md) — Hit-or-miss operation for regions using the Golay alphabet.

- [`HitOrMissSeq`](hit_or_miss_seq.md) — Hit-or-miss operation for regions using the Golay alphabet (sequential).

- [`MorphHat`](morph_hat.md) — Compute the union of [`BottomHat`](bottom_hat.md) and [`TopHat`](top_hat.md).

- [`MorphSkeleton`](morph_skeleton.md) — Compute the morphological skeleton of a region.

- [`MorphSkiz`](morph_skiz.md) — Thinning of a region.

- [`OpeningGolay`](opening_golay.md) — Open a region with an element from the Golay alphabet.

- [`OpeningSeg`](opening_seg.md) — Separate overlapping regions.

- [`Thickening`](thickening.md) — Add the result of a hit-or-miss operation to a region.

- [`ThickeningGolay`](thickening_golay.md) — Add the result of a hit-or-miss operation to a region (using a Golay
  structuring element).

- [`ThickeningSeq`](thickening_seq.md) — Add the result of a hit-or-miss operation to a region (sequential).

- [`Thinning`](thinning.md) — Remove the result of a hit-or-miss operation from a region.

- [`ThinningGolay`](thinning_golay.md) — Remove the result of a hit-or-miss operation from a region (using a
  Golay structuring element).

- [`ThinningSeq`](thinning_seq.md) — Remove the result of a hit-or-miss operation from a region (sequential).
