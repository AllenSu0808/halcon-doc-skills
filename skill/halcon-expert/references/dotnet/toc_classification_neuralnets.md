## Neural Nets

#### List of Operators

- [`AddClassTrainDataMlp`](add_class_train_data_mlp.md) — Add training data to a multilayer perceptron (MLP).

- [`AddSampleClassMlp`](add_sample_class_mlp.md) — Add a training sample to the training data of a multilayer
  perceptron.

- [`ClassifyClassMlp`](classify_class_mlp.md) — Calculate the class of a feature vector by a multilayer perceptron.

- [`ClearClassMlp`](clear_class_mlp.md) — Clear a multilayer perceptron.

- [`ClearSamplesClassMlp`](clear_samples_class_mlp.md) — Clear the training data of a multilayer perceptron.

- [`CreateClassMlp`](create_class_mlp.md) — Create a multilayer perceptron for classification or regression.

- [`DeserializeClassMlp`](deserialize_class_mlp.md) — Deserialize a serialized multilayer perceptron.

- [`EvaluateClassMlp`](evaluate_class_mlp.md) — Calculate the evaluation of a feature vector by a multilayer
  perceptron.

- [`GetClassTrainDataMlp`](get_class_train_data_mlp.md) — Get the training data of a multilayer perceptron (MLP).

- [`GetParamsClassMlp`](get_params_class_mlp.md) — Return the parameters of a multilayer perceptron.

- [`GetPrepInfoClassMlp`](get_prep_info_class_mlp.md) — Compute the information content of the preprocessed feature vectors
  of a multilayer perceptron.

- [`GetRegularizationParamsClassMlp`](get_regularization_params_class_mlp.md) — Return the regularization parameters of a multilayer perceptron.

- [`GetRejectionParamsClassMlp`](get_rejection_params_class_mlp.md) — Get the parameters of a rejection class.

- [`GetSampleClassMlp`](get_sample_class_mlp.md) — Return a training sample from the training data of a multilayer
  perceptron.

- [`GetSampleNumClassMlp`](get_sample_num_class_mlp.md) — Return the number of training samples stored in the training data of
  a multilayer perceptron.

- [`ReadClassMlp`](read_class_mlp.md) — Read a multilayer perceptron from a file.

- [`ReadSamplesClassMlp`](read_samples_class_mlp.md) — Read the training data of a multilayer perceptron from a file.

- [`SelectFeatureSetMlp`](select_feature_set_mlp.md) — Selects an optimal combination of features to classify the provided data.

- [`SerializeClassMlp`](serialize_class_mlp.md) — Serialize a multilayer perceptron (MLP).

- [`SetRegularizationParamsClassMlp`](set_regularization_params_class_mlp.md) — Set the regularization parameters of a multilayer perceptron.

- [`SetRejectionParamsClassMlp`](set_rejection_params_class_mlp.md) — Set the parameters of a rejection class.

- [`TrainClassMlp`](train_class_mlp.md) — Train a multilayer perceptron.

- [`WriteClassMlp`](write_class_mlp.md) — Write a multilayer perceptron to a file.

- [`WriteSamplesClassMlp`](write_samples_class_mlp.md) — Write the training data of a multilayer perceptron to a file.
