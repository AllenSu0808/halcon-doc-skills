# ReadTuple (Operator)

## Name

`ReadTuple` — Read a tuple from a file.

## Signature

`static void HOperatorSet.ReadTuple(HTuple fileName, out HTuple tuple)`

`static HTuple HMisc.ReadTuple(string fileName)`

`static HTuple HTuple.ReadTuple(HTuple fileName)`

## Description

The operator `ReadTuple` reads the contents of *`fileName`* and
converts it into *`tuple`*. The default HALCON file extension for the
tuple is 'tup'. The file has to be generated by [`WriteTuple`](write_tuple.md).

## Execution Information

- Multithreading type: independent (runs in parallel even with exclusive operators).
- Multithreading scope: global (may be called from any thread).
- Processed without parallelization.

## Parameters

**`fileName`** (input_control)  filename.read `→` [HTuple](HTuple.md) (*string*)

Name of the file to be read.

File extension:
.`tup`

**`tuple`** (output_control)  tuple(-array) `→` [HTuple](HTuple.md) (*double* / int / long / string)

Tuple with any kind of data.

## Result

If the parameters are correct the operator `ReadTuple`
returns the value 2 (
H_MSG_TRUE)
. Otherwise an exception is raised.
