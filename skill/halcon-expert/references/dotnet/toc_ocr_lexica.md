## Lexica

#### List of Operators

- [`ClearLexicon`](clear_lexicon.md) — Clear a lexicon.

- [`CreateLexicon`](create_lexicon.md) — Create a lexicon from a tuple of words.

- [`ImportLexicon`](import_lexicon.md) — Create a lexicon from a text file.

- [`InspectLexicon`](inspect_lexicon.md) — Query all words from a lexicon.

- [`LookupLexicon`](lookup_lexicon.md) — Check if a word is contained in a lexicon.

- [`SuggestLexicon`](suggest_lexicon.md) — Find a similar word in a lexicon.
