## I/O Devices

#### List of Operators

- [`CloseIoChannel`](close_io_channel.md) — Close I/O channels.

- [`CloseIoDevice`](close_io_device.md) — Close the specified I/O device.

- [`ControlIoChannel`](control_io_channel.md) — Perform an action on I/O channels.

- [`ControlIoDevice`](control_io_device.md) — Perform an action on the I/O device.

- [`ControlIoInterface`](control_io_interface.md) — Perform an action on the I/O interface.

- [`GetIoChannelParam`](get_io_channel_param.md) — Query specific parameters of I/O channels.

- [`GetIoDeviceParam`](get_io_device_param.md) — Query settings of an I/O device instance.

- [`OpenIoChannel`](open_io_channel.md) — Open and configure I/O channels.

- [`OpenIoDevice`](open_io_device.md) — Open and configure an I/O device.

- [`QueryIoDevice`](query_io_device.md) — Query information about channels of the specified I/O device.

- [`QueryIoInterface`](query_io_interface.md) — Query information about the specified I/O device interface.

- [`ReadIoChannel`](read_io_channel.md) — Read a value from the specified I/O channels.

- [`SetIoChannelParam`](set_io_channel_param.md) — Set specific parameters of I/O channels.

- [`SetIoDeviceParam`](set_io_device_param.md) — Configure a specific I/O device instance.

- [`WriteIoChannel`](write_io_channel.md) — Write a value to the specified I/O channels.
