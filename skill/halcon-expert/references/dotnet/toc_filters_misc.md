## Misc

#### List of Operators

- [`ConvolChannels`](convol_channels.md) — Perform a convolution along the channel dimension.

- [`ConvolImage`](convol_image.md) — Calculate the correlation between an image and an arbitrary filter mask

- [`DeviationN`](deviation_n.md) — Calculate standard deviation over several channels.

- [`ExpandDomainGray`](expand_domain_gray.md) — Expand the domain of an image and set the gray values in the
  expanded domain.

- [`GenSavitzkyGolayFilter`](gen_savitzky_golay_filter.md) — Compute the filter coefficients of a Savitzky-Golay filter.

- [`GrayInside`](gray_inside.md) — Calculate the lowest possible gray value on an arbitrary path to the
  image border for each point in the image.

- [`GraySkeleton`](gray_skeleton.md) — Thinning of gray value images.

- [`LutTrans`](lut_trans.md) — Transform an image with a gray-value look-up-table

- [`Symmetry`](symmetry.md) — Symmetry of gray values along a row.

- [`TopographicSketch`](topographic_sketch.md) — Compute the topographic primal sketch of an image.
