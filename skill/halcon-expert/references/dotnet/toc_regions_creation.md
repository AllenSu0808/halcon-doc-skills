## Creation

#### List of Operators

- [`GenCheckerRegion`](gen_checker_region.md) — Create a checkered region.

- [`GenCircle`](gen_circle.md) — Create a circle.

- [`GenCircleSector`](gen_circle_sector.md) — Create a circle sector.

- [`GenEllipse`](gen_ellipse.md) — Create an ellipse.

- [`GenEllipseSector`](gen_ellipse_sector.md) — Create an ellipse sector.

- [`GenEmptyRegion`](gen_empty_region.md) — Create an empty region.

- [`GenGridRegion`](gen_grid_region.md) — Create a region from lines or pixels.

- [`GenRandomRegion`](gen_random_region.md) — Create a random region.

- [`GenRandomRegions`](gen_random_regions.md) — Create random regions like circles, rectangles and ellipses.

- [`GenRectangle1`](gen_rectangle1.md) — Create a rectangle parallel to the coordinate axes.

- [`GenRectangle2`](gen_rectangle2.md) — Create a rectangle of any orientation.

- [`GenRegionContourXld`](gen_region_contour_xld.md) — Create a region from an XLD contour.

- [`GenRegionHisto`](gen_region_histo.md) — Convert a histogram into a region.

- [`GenRegionHline`](gen_region_hline.md) — Store input lines described in Hesse normal form as regions.

- [`GenRegionLine`](gen_region_line.md) — Store input lines as regions.

- [`GenRegionPoints`](gen_region_points.md) — Store individual pixels as image region.

- [`GenRegionPolygon`](gen_region_polygon.md) — Store a polygon as a region.

- [`GenRegionPolygonFilled`](gen_region_polygon_filled.md) — Store a polygon as a “filled” region.

- [`GenRegionPolygonXld`](gen_region_polygon_xld.md) — Create a region from an XLD polygon.

- [`GenRegionRuns`](gen_region_runs.md) — Create a region from a runlength coding.

- [`LabelToRegion`](label_to_region.md) — Extract regions with equal gray values from an image.
