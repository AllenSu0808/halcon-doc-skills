## Information

#### List of Operators

- [`GetChapterInfo`](get_chapter_info.md) — Get information concerning the chapters on operators.

- [`GetKeywords`](get_keywords.md) — Get keywords which are assigned to operators.

- [`GetOperatorInfo`](get_operator_info.md) — Get information concerning a HALCON-operator.

- [`GetOperatorName`](get_operator_name.md) — Get operators with the given string as a substring of their name.

- [`GetParamInfo`](get_param_info.md) — Get information concerning the operator parameters.

- [`GetParamNames`](get_param_names.md) — Get the names of the parameters of a HALCON-operator.

- [`GetParamNum`](get_param_num.md) — Get number of the different parameter classes of a HALCON-operator.

- [`GetParamTypes`](get_param_types.md) — Get default data type for the control parameters of a HALCON-operator.

- [`QueryOperatorInfo`](query_operator_info.md) — Query slots concerning information with relation to the operator [`GetOperatorInfo`](get_operator_info.md).

- [`QueryParamInfo`](query_param_info.md) — Query slots of the online-information concerning the operator [`GetParamInfo`](get_param_info.md).

- [`SearchOperator`](search_operator.md) — Search names of all operators assigned to one keyword.
