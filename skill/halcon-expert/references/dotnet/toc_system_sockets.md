## Sockets

#### List of Operators

- [`CloseSocket`](close_socket.md) — Close a socket.

- [`GetNextSocketDataType`](get_next_socket_data_type.md) — Determine the HALCON data type of the next socket data.

- [`GetSocketDescriptor`](get_socket_descriptor.md) — Get the socket descriptor of a socket used by the operating system.

- [`GetSocketParam`](get_socket_param.md) — Get the value of a socket parameter.

- [`OpenSocketAccept`](open_socket_accept.md) — Open a socket that accepts connection requests.

- [`OpenSocketConnect`](open_socket_connect.md) — Open a socket and connect it to an accepting socket.

- [`ReceiveData`](receive_data.md) — Receive arbitrary data from external devices or applications using a
  generic socket connection.

- [`ReceiveImage`](receive_image.md) — Receive an image over a socket connection.

- [`ReceiveRegion`](receive_region.md) — Receive regions over a socket connection.

- [`ReceiveSerializedItem`](receive_serialized_item.md) — Receive a serialized item over a socket connection.

- [`ReceiveTuple`](receive_tuple.md) — Receive a tuple over a socket connection.

- [`ReceiveXld`](receive_xld.md) — Receive an XLD object over a socket connection.

- [`SendData`](send_data.md) — Send arbitrary data to external devices or applications using a
  generic socket communication.

- [`SendImage`](send_image.md) — Send an image over a socket connection.

- [`SendRegion`](send_region.md) — Send regions over a socket connection.

- [`SendSerializedItem`](send_serialized_item.md) — Send a serialized item over a socket connection.

- [`SendTuple`](send_tuple.md) — Send a tuple over a socket connection.

- [`SendXld`](send_xld.md) — Send an XLD object over a socket connection.

- [`SetSocketParam`](set_socket_param.md) — Set a socket parameter.

- [`SocketAcceptConnect`](socket_accept_connect.md) — Accept a connection request on a listening socket of the protocol type
  *`"HALCON"`* or *`"TCP"`*/*`"TCP4"`*/*`"TCP6"`*.
