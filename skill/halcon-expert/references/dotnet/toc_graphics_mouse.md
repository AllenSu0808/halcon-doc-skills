## Mouse

#### List of Operators

- [`GetMbutton`](get_mbutton.md) — Wait until a mouse button is pressed.

- [`GetMbuttonSubPix`](get_mbutton_sub_pix.md) — Wait until a mouse button is pressed and get the subpixel mouse position.

- [`GetMposition`](get_mposition.md) — Query the mouse position.

- [`GetMpositionSubPix`](get_mposition_sub_pix.md) — Query the subpixel mouse position.

- [`GetMshape`](get_mshape.md) — Query the current mouse pointer shape.

- [`QueryMshape`](query_mshape.md) — Query all available mouse pointer shapes.

- [`SendMouseDoubleClickEvent`](send_mouse_double_click_event.md) — Send an event to a buffer window signaling a mouse double click event.

- [`SendMouseDownEvent`](send_mouse_down_event.md) — Send an event to a window buffer signaling a mouse down event.

- [`SendMouseDragEvent`](send_mouse_drag_event.md) — Send an event to a buffer window signaling a mouse drag event.

- [`SendMouseUpEvent`](send_mouse_up_event.md) — Send an event to a buffer window signaling a mouse up event.

- [`SetMshape`](set_mshape.md) — Set the current mouse pointer shape.
