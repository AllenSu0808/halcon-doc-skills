## 3D Transformations

#### List of Operators

- [`AffineTransPoint3d`](affine_trans_point_3d.md) — Apply an arbitrary affine 3D transformation to points.

- [`DeserializeHomMat3d`](deserialize_hom_mat3d.md) — Deserialize a serialized homogeneous 3D transformation matrix.

- [`HomMat3dCompose`](hom_mat3d_compose.md) — Multiply two homogeneous 3D transformation matrices.

- [`HomMat3dDeterminant`](hom_mat3d_determinant.md) — Compute the determinant of a homogeneous 3D transformation matrix.

- [`HomMat3dIdentity`](hom_mat3d_identity.md) — Generate the homogeneous transformation matrix of the identical 3D
  transformation.

- [`HomMat3dInvert`](hom_mat3d_invert.md) — Invert a homogeneous 3D transformation matrix.

- [`HomMat3dRotate`](hom_mat3d_rotate.md) — Add a rotation to a homogeneous 3D transformation matrix.

- [`HomMat3dRotateLocal`](hom_mat3d_rotate_local.md) — Add a rotation to a homogeneous 3D transformation matrix.

- [`HomMat3dScale`](hom_mat3d_scale.md) — Add a scaling to a homogeneous 3D transformation matrix.

- [`HomMat3dScaleLocal`](hom_mat3d_scale_local.md) — Add a scaling to a homogeneous 3D transformation matrix.

- [`HomMat3dToPose`](hom_mat3d_to_pose.md) — Convert a homogeneous transformation matrix into a 3D pose.

- [`HomMat3dTranslate`](hom_mat3d_translate.md) — Add a translation to a homogeneous 3D transformation matrix.

- [`HomMat3dTranslateLocal`](hom_mat3d_translate_local.md) — Add a translation to a homogeneous 3D transformation matrix.

- [`HomMat3dTranspose`](hom_mat3d_transpose.md) — Transpose a homogeneous 3D transformation matrix.

- [`PointPlueckerLineToHomMat3d`](point_pluecker_line_to_hom_mat3d.md) — Approximate a 3D affine transformation from 3D point-to-line
  correspondences.

- [`PoseToHomMat3d`](pose_to_hom_mat3d.md) — Convert a 3D pose into a homogeneous transformation matrix.

- [`ProjectiveTransHomPoint3d`](projective_trans_hom_point_3d.md) — Project a homogeneous 3D point using a projective transformation
  matrix.

- [`ProjectiveTransPoint3d`](projective_trans_point_3d.md) — Project a 3D point using a projective transformation matrix.

- [`SerializeHomMat3d`](serialize_hom_mat3d.md) — Serialize a homogeneous 3D transformation matrix.

- [`VectorToHomMat3d`](vector_to_hom_mat3d.md) — Approximate a 3D transformation from point correspondences.
