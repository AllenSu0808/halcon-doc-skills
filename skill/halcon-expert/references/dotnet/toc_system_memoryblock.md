## Memory Block

#### List of Operators

- [`CompareMemoryBlock`](compare_memory_block.md) — Compare contents of memory blocks regarding equality.

- [`CreateMemoryBlockExtern`](create_memory_block_extern.md) — Create a memory block from an external pointer.

- [`CreateMemoryBlockExternCopy`](create_memory_block_extern_copy.md) — Create a memory block from an external pointer by copying.

- [`GetMemoryBlockPtr`](get_memory_block_ptr.md) — Return the data pointer and size of a memory block.

- [`ReadMemoryBlock`](read_memory_block.md) — Read a memory block from a file.

- [`WriteMemoryBlock`](write_memory_block.md) — Write a memory block to a file.
