## Data Containers

#### List of Operators

- [`CopyDict`](copy_dict.md) — Copy a dictionary.

- [`CreateDict`](create_dict.md) — Create a new empty dictionary.

- [`DictToJson`](dict_to_json.md) — Transform a dictionary into a JSON string.

- [`GetDictObject`](get_dict_object.md) — Retrieve an object associated with the key from the dictionary.

- [`GetDictParam`](get_dict_param.md) — Query dictionary parameters or information about a dictionary.

- [`GetDictTuple`](get_dict_tuple.md) — Retrieve a tuple associated with the key from the dictionary.

- [`JsonToDict`](json_to_dict.md) — Transform a JSON string into a dictionary.

- [`ReadDict`](read_dict.md) — Read a dictionary from a file.

- [`RemoveDictKey`](remove_dict_key.md) — Remove keys from a dictionary.

- [`SetDictObject`](set_dict_object.md) — Add a key/object pair to the dictionary.

- [`SetDictTuple`](set_dict_tuple.md) — Add a key/tuple pair to the dictionary.

- [`SetDictTupleAt`](set_dict_tuple_at.md) — Assignment of one or several values to one or several tuple elements
  in a dictionary

- [`WriteDict`](write_dict.md) — Write a dictionary to a file.
