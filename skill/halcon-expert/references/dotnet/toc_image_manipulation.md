## Manipulation

#### List of Operators

- [`OverpaintGray`](overpaint_gray.md) — Overpaint the gray values of an image.

- [`OverpaintRegion`](overpaint_region.md) — Overpaint regions in an image.

- [`PaintGray`](paint_gray.md) — Paint the gray values of an image into another image.

- [`PaintRegion`](paint_region.md) — Paint regions into an image.

- [`PaintXld`](paint_xld.md) — Paint XLD objects into an image.

- [`SetGrayval`](set_grayval.md) — Set single gray values in an image.
