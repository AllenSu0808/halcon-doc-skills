## Window

#### List of Operators

- [`ClearWindow`](clear_window.md) — Delete the contents of an output window.

- [`CloseWindow`](close_window.md) — Close an output window.

- [`CopyRectangle`](copy_rectangle.md) — Copy all pixels within rectangles between output windows.

- [`DumpWindow`](dump_window.md) — Write the window content to a file.

- [`DumpWindowImage`](dump_window_image.md) — Write the window content in an image object.

- [`FlushBuffer`](flush_buffer.md) — Flush the contents of a window.

- [`GetDispObjectModel3dInfo`](get_disp_object_model_3d_info.md) — Get the depth or the index of a displayed 3D object model.

- [`GetOsWindowHandle`](get_os_window_handle.md) — Get the operating system window handle.

- [`GetWindowAttr`](get_window_attr.md) — Get window characteristics.

- [`GetWindowExtents`](get_window_extents.md) — Information about a window's size and position.

- [`GetWindowPointer3`](get_window_pointer3.md) — Access to a window's pixel data.

- [`GetWindowType`](get_window_type.md) — Get the window type.

- [`NewExternWindow`](new_extern_window.md) — Create a virtual graphics window under Windows.

- [`OpenWindow`](open_window.md) — Open a graphics window.

- [`QueryWindowType`](query_window_type.md) — Query all available window types.

- [`SetWindowAttr`](set_window_attr.md) — Set window characteristics.

- [`SetWindowDc`](set_window_dc.md) — Set the device context of a virtual graphics window (Windows NT).

- [`SetWindowExtents`](set_window_extents.md) — Modify position and size of a window.

- [`SetWindowType`](set_window_type.md) — Specify a window type.

- [`UnprojectCoordinates`](unproject_coordinates.md) — Calculates image coordinates for a point in a 3D plot window.

- [`UpdateWindowPose`](update_window_pose.md) — Modify the pose of a 3D plot.
