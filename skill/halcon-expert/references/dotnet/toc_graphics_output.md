## Output

#### List of Operators

- [`DispArc`](disp_arc.md) — Displays circular arcs in a window.

- [`DispArrow`](disp_arrow.md) — Displays arrows in a window.

- [`DispChannel`](disp_channel.md) — Displays images with several channels.

- [`DispCircle`](disp_circle.md) — Displays circles in a window.

- [`DispColor`](disp_color.md) — Displays a color (RGB) image

- [`DispCross`](disp_cross.md) — Displays crosses in a window.

- [`DispEllipse`](disp_ellipse.md) — Displays ellipses.

- [`DispImage`](disp_image.md) — Displays gray value images.

- [`DispLine`](disp_line.md) — Draws lines in a window.

- [`DispObj`](disp_obj.md) — Displays image objects (image, region, XLD).

- [`DispObjectModel3d`](disp_object_model_3d.md) — Display 3D object models.

- [`DispPolygon`](disp_polygon.md) — Displays a polyline.

- [`DispRectangle1`](disp_rectangle1.md) — Display of rectangles aligned to the coordinate axes.

- [`DispRectangle2`](disp_rectangle2.md) — Displays arbitrarily oriented rectangles.

- [`DispRegion`](disp_region.md) — Displays regions in a window.

- [`DispXld`](disp_xld.md) — Display an XLD object.
