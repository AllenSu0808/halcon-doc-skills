## Features

#### List of Operators

- [`AreaCenterGray`](area_center_gray.md) — Compute the area and center of gravity of a region in a gray value
  image.

- [`CoocFeatureImage`](cooc_feature_image.md) — Calculate a co-occurrence matrix and derive gray value features thereof.

- [`CoocFeatureMatrix`](cooc_feature_matrix.md) — Calculate gray value features from a co-occurrence matrix.

- [`EllipticAxisGray`](elliptic_axis_gray.md) — Compute the orientation and major axes of a region in a gray value
  image.

- [`EntropyGray`](entropy_gray.md) — Determine the entropy and anisotropy of images.

- [`EstimateNoise`](estimate_noise.md) — Estimate the image noise from a single image.

- [`FitSurfaceFirstOrder`](fit_surface_first_order.md) — Calculate gray value moments and approximation by a first order surface
  (plane).

- [`FitSurfaceSecondOrder`](fit_surface_second_order.md) — Calculate gray value moments and approximation by a second order surface.

- [`FuzzyEntropy`](fuzzy_entropy.md) — Determine the fuzzy entropy of regions.

- [`FuzzyPerimeter`](fuzzy_perimeter.md) — Calculate the fuzzy perimeter of a region.

- [`GenCoocMatrix`](gen_cooc_matrix.md) — Calculate the co-occurrence matrix of a region in an image.

- [`GrayFeatures`](gray_features.md) — Calculates gray value features for a set of regions.

- [`GrayHisto`](gray_histo.md) — Calculate the gray value distribution.

- [`GrayHistoAbs`](gray_histo_abs.md) — Calculate the gray value distribution.

- [`GrayHistoRange`](gray_histo_range.md) — Calculate the gray value distribution of a single channel image within a
  certain gray value range.

- [`GrayProjections`](gray_projections.md) — Calculate horizontal and vertical gray-value projections.

- [`Histo2dim`](histo_2dim.md) — Calculate the histogram of two-channel gray value images.

- [`Intensity`](intensity.md) — Calculate the mean and deviation of gray values.

- [`MinMaxGray`](min_max_gray.md) — Determine the minimum and maximum gray values within regions.

- [`MomentsGrayPlane`](moments_gray_plane.md) — Calculate gray value moments and approximation by a plane.

- [`PlaneDeviation`](plane_deviation.md) — Calculate the deviation of the gray values from the approximating
  image plane.

- [`SelectGray`](select_gray.md) — Select regions based on gray value features.

- [`ShapeHistoAll`](shape_histo_all.md) — Determine a histogram of features along all threshold values.

- [`ShapeHistoPoint`](shape_histo_point.md) — Determine a histogram of features along all threshold values.
