## Deformable

#### List of Operators

- [`ClearDeformableModel`](clear_deformable_model.md) — Free the memory of a deformable model.

- [`CreateLocalDeformableModel`](create_local_deformable_model.md) — Creates a deformable model for local, deformable matching.

- [`CreateLocalDeformableModelXld`](create_local_deformable_model_xld.md) — Prepare a deformable model for local deformable matching from XLD contours.

- [`CreatePlanarCalibDeformableModel`](create_planar_calib_deformable_model.md) — Create a deformable model for calibrated perspective matching.

- [`CreatePlanarCalibDeformableModelXld`](create_planar_calib_deformable_model_xld.md) — Prepare a deformable model for planar calibrated matching from XLD contours.

- [`CreatePlanarUncalibDeformableModel`](create_planar_uncalib_deformable_model.md) — Creates a deformable model for uncalibrated, perspective matching.

- [`CreatePlanarUncalibDeformableModelXld`](create_planar_uncalib_deformable_model_xld.md) — Prepare a deformable model for planar uncalibrated matching
  from XLD contours.

- [`DeserializeDeformableModel`](deserialize_deformable_model.md) — Deserialize a deformable model.

- [`DetermineDeformableModelParams`](determine_deformable_model_params.md) — Determine the parameters of a deformable model.

- [`FindLocalDeformableModel`](find_local_deformable_model.md) — Find the best matches of a local deformable model in an image.

- [`FindPlanarCalibDeformableModel`](find_planar_calib_deformable_model.md) — Find the best matches of a calibrated deformable model in an image and return
  their 3D pose.

- [`FindPlanarUncalibDeformableModel`](find_planar_uncalib_deformable_model.md) — Find the best matches of a planar projective invariant deformable model
  in an image.

- [`GetDeformableModelContours`](get_deformable_model_contours.md) — Return the contour representation of a deformable model.

- [`GetDeformableModelOrigin`](get_deformable_model_origin.md) — Return the origin (reference point) of a deformable model.

- [`GetDeformableModelParams`](get_deformable_model_params.md) — Return the parameters of a deformable model.

- [`ReadDeformableModel`](read_deformable_model.md) — Read a deformable model from a file.

- [`SerializeDeformableModel`](serialize_deformable_model.md) — Serialize a deformable model.

- [`SetDeformableModelOrigin`](set_deformable_model_origin.md) — Set the origin (reference point) of a deformable model.

- [`SetDeformableModelParam`](set_deformable_model_param.md) — Set selected parameters of the deformable model.

- [`SetLocalDeformableModelMetric`](set_local_deformable_model_metric.md) — Set the metric of a local deformable model that was created from XLD
  contours.

- [`SetPlanarCalibDeformableModelMetric`](set_planar_calib_deformable_model_metric.md) — Set the metric of a planar calibrated deformable model that was created
  from XLD contours.

- [`SetPlanarUncalibDeformableModelMetric`](set_planar_uncalib_deformable_model_metric.md) — Set the metric of a planar uncalibrated deformable model that was created
  from XLD contours.

- [`WriteDeformableModel`](write_deformable_model.md) — Write a deformable model to a file.
